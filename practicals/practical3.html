TOPIC 01

Implicit Type Casting

Implicit type casting is the automatic conversion of one data type into another by the C++ compiler.

Theory

Type casting is the process of converting a value from one data type to another. In implicit type casting, the conversion is performed automatically by the compiler.

This commonly occurs when a value of a smaller or compatible type is assigned to a variable of another suitable type. For example, an integer can be converted automatically to a floating-point value.

Smaller / Compatible Type → Larger / Compatible Type
🌍

Real-Life Example

Consider a shopping application where the quantity is stored as an integer, while the price calculation uses decimal values. During an expression, the integer quantity can participate automatically in a floating-point calculation.

Where & How Is It Used?

Calculations

Used when values of different compatible types participate in an expression.

Assignments

A value can automatically be converted when assigned to a compatible data type.

Mixed Expressions

Useful when integer and floating point values are used together.

PROBLEM 01

Integer to Float

Problem Statement

Write a C++ program to demonstrate implicit conversion of an integer value into a floating-point value.

Concept

When an integer value is assigned to a floating-point variable, C++ can automatically convert the integer into a floating-point value.

Algorithm

  1. Start.
  2. Declare an integer variable.
  3. Assign an integer value.
  4. Declare a floating-point variable.
  5. Assign the integer value to the floating-point variable.
  6. Display the converted value.
  7. Stop.

C++ Program 

#include <iostream>
using namespace std;

int main()
{
    int number = 25;

    float value = number;

    cout << "Integer value = "
         << number << endl;

    cout << "Float value = "
         << value;

    return 0;
}

Expected Output 

Integer value = 25
Float value = 25
TYPE CASTING VISUALIZATION

Automatic Conversion

The compiler automatically converts the integer value to a floating-point value.

int 25
compiler →
float 25.0

Real-Life Connection

In a billing calculation, an integer quantity can automatically participate in a calculation involving a decimal price.

Key Points

  • Conversion is performed automatically.
  • No casting operator is explicitly written by the programmer.
  • The compiler performs the required compatible conversion.

Common Errors

Unexpected Conversion

Always check the data type of the destination variable.

Data Loss

Not every conversion is completely lossless.

TOPIC 02

Explicit Type Casting

Explicit type casting is the manual conversion of a value from one data type to another by the programmer.

Theory

In explicit type casting, the programmer specifically instructs the compiler to convert a value into a particular data type.

C++ supports different casting mechanisms. A simple C++ cast can be written using the target type before the value, such as (float) or (int). C++ also provides named casts such as static_cast<type>().

Original Type → Explicit Cast → Required Type
🌍

Real-Life Example

Suppose a marksheet stores total marks and number of subjects as integers. To calculate an accurate average, the programmer can explicitly convert one value to a floating-point type before performing division.

Where & How Is It Used?

Average Calculation

Convert integer values to floating point to obtain decimal results.

Data Conversion

Convert a value into a required data type for a specific operation.

Controlled Conversion

The programmer explicitly decides when and how conversion occurs.

PROBLEM 01

Float to Integer

Problem Statement

Write a C++ program to demonstrate explicit conversion of a floating-point value into an integer value.

Syntax

int(value)

static_cast<int>(value)

Algorithm

  1. Start.
  2. Declare a floating-point variable.
  3. Assign a decimal value.
  4. Explicitly convert the value into an integer.
  5. Display the result.
  6. Stop.

C++ Program 

#include <iostream>
using namespace std;

int main()
{
    float value = 25.75;

    int number = static_cast<int>(value);

    cout << "Original value = "
         << value << endl;

    cout << "Integer value = "
         << number;

    return 0;
}

Expected Output 

Original value = 25.75
Integer value = 25
EXPLICIT CASTING

Programmer-Controlled Conversion

float 25.75
static_cast<int> →
int 25

Important Note

Converting a floating-point value to an integer discards the fractional part. Therefore, 25.75 becomes 25.

Key Points

  • Explicit conversion is controlled by the programmer.
  • static_cast is the preferred C++ style for many ordinary conversions.
  • Fractional information can be lost when converting float to int.

PROBLEM 03

Average Calculation

Problem Statement

Write a C++ program to calculate the average of integer marks using explicit type casting to obtain a decimal result.

Concept

If two integers are divided directly, integer division may discard the fractional part. Explicitly converting one operand to float allows the calculation to produce a decimal result.

Algorithm

  1. Start.
  2. Declare total marks and number of subjects.
  3. Convert total marks into float.
  4. Divide by the number of subjects.
  5. Display the average.
  6. Stop.

C++ Program 

#include <iostream>
using namespace std;

int main()
{
    int total = 427;
    int subjects = 5;

    float average =
        static_cast<float>(total) / subjects;

    cout << "Average = "
         << average;

    return 0;
}

Expected Output 

Average = 85.4
CALCULATION VISUALIZATION

Avoiding Integer Division

int 427 → float 427.0 ÷ 5 85.4

Real-Life Connection

This approach is useful in student marksheets, percentage calculations, measurements and financial calculations where decimal precision is required.

Key Points

  • Explicit casting can control the type used in an expression.
  • Converting an operand to float can avoid unwanted integer division.
  • static_cast clearly communicates the programmer's intention.

Common Errors

Integer Division

Dividing two integers can produce an integer result.

Wrong Target Type

Choose the target data type according to the required result.

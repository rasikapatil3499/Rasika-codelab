CONCEPT

Understanding Polymorphism

What is Polymorphism?

Polymorphism means “many forms”. In C++, polymorphism allows the same function name, operator or interface to perform different operations depending on the context.

Polymorphism is an important feature of object-oriented programming because it allows programs to be flexible, reusable and easier to extend.

Real-Life Example

Consider the word “print”. A system may print a document, a photograph or a report. The basic operation is the same, but the behavior can differ depending on what is being printed.

Similarly, C++ can use the same function or interface to perform different operations.

Compile-Time and Runtime Polymorphism

Compile-Time Polymorphism

The compiler determines which function or operator operation should be used before the program runs. Function overloading and operator overloading are common examples.

Runtime Polymorphism

The function to execute is selected while the program is running. Function overriding through virtual functions is a common example.

Function Overloading

Function overloading allows multiple functions to have the same name with different parameter lists.

PROBLEM 01.1

Area Calculation

Problem Statement

Write a C++ program to demonstrate function overloading by creating overloaded area() functions to calculate the area of a square, rectangle and circle.

Theory / Concept

The same function name area() is used with different parameter lists. The compiler selects the appropriate function based on the arguments supplied.

SYNTAX

Function Overloading

returnType functionName(int value)
{
}

returnType functionName(int value1, int value2)
{
}

returnType functionName(float value)
{
}

Algorithm

  1. Define a class Calculator.
  2. Create overloaded area() functions.
  3. Use one parameter for square.
  4. Use two parameters for rectangle.
  5. Use a floating-point parameter for circle.
  6. Call the functions with appropriate arguments.
  7. Display all calculated areas.

C++ Program

#include <iostream>

using namespace std;

class Calculator
{
public:

    int area(int side)
    {
        return side * side;
    }

    int area(int length, int breadth)
    {
        return length * breadth;
    }

    float area(float radius)
    {
        return 3.14f * radius * radius;
    }
};

int main()
{
    Calculator c;

    cout << "Square Area: " << c.area(5) << endl;
    cout << "Rectangle Area: " << c.area(10, 4) << endl;
    cout << "Circle Area: " << c.area(3.0f) << endl;

    return 0;
}

Expected Output

Square Area: 25
Rectangle Area: 40
Circle Area: 28.26
VISUAL EXPLANATION

Compiler Selects the Matching Function

area(5)1 integer
→
Square5 × 5
→
25Result

Program Explanation

  • All three functions have the same name: area().
  • The parameter lists are different.
  • The compiler chooses the matching overloaded function.
  • This is compile-time polymorphism.

Real-Life Connection

A calculator application can use the same operation name while accepting different kinds or numbers of inputs.

Key Points

  • Function name remains the same.
  • Parameter list must differ.
  • Return type alone cannot overload a function.

Common Errors

Same Parameters

Overloaded functions must have different parameter lists.

Return Type Only

Changing only the return type does not create a valid overload.

Ambiguous Call

Use arguments that clearly match one overloaded function.

Wrong Formula

Use the correct formula for each shape.

Operator Overloading

Operator overloading gives an existing C++ operator a meaningful behavior for objects of a user-defined class.

PROBLEM 02.1

Add Two Complex Numbers

Problem Statement

Write a C++ program to overload the + operator to add two complex numbers.

Theory / Concept

The + operator normally works with built-in numeric types. Operator overloading allows the same operator to work meaningfully with Complex objects.

SYNTAX

Operator Function

ClassName operator+(const ClassName &obj)
{
    // operation
}

Algorithm

  1. Create a Complex class with real and imaginary parts.
  2. Define the overloaded + operator.
  3. Add the corresponding real parts.
  4. Add the corresponding imaginary parts.
  5. Return the resulting Complex object.
  6. Display the result.

C++ Program

#include <iostream>

using namespace std;

class Complex
{
    int real;
    int imag;

public:
    Complex(int r = 0, int i = 0)
    {
        real = r;
        imag = i;
    }

    Complex operator+(const Complex &c)
    {
        return Complex(real + c.real, imag + c.imag);
    }

    void display()
    {
        cout << real << " + " << imag << "i" << endl;
    }
};

int main()
{
    Complex c1(3, 4);
    Complex c2(5, 2);

    Complex c3 = c1 + c2;

    cout << "Result: ";
    c3.display();

    return 0;
}

Expected Output

Result: 8 + 6i
VISUAL EXPLANATION

Object + Object

+
c25 + 2i
→
c38 + 6i

Program Explanation

  • The + operator is overloaded inside Complex.
  • Two Complex objects can now be added using c1 + c2.
  • The operator function returns a new Complex object.

Real-Life Connection

Mathematical libraries can represent numbers such as complex numbers as objects and make expressions easier to read.

Key Points

  • Operators can be overloaded for user-defined types.
  • The operator keeps its familiar symbol.
  • The overloaded operation should have a logical meaning.

Common Errors

Return Type

Return a suitable result object from the operator function.

Wrong Members

Add corresponding real and imaginary parts.

Reference

Passing the operand by const reference avoids unnecessary copying.

Operator

Use the correct operator symbol in the overloaded function name.

PROBLEM 02.3

Add Two Distance Objects

Problem Statement

Write a C++ program to overload the + operator to add two distance objects containing feet and inches.

Theory / Concept

The + operator can be customized to add distance objects and handle conversion when inches reach 12.

SYNTAX

Distance Addition

Distance operator+(const Distance &d)
{
    Distance temp;

    // add members
    // normalize units

    return temp;
}

Algorithm

  1. Create Distance with feet and inches.
  2. Overload +.
  3. Add feet and inches separately.
  4. If inches are 12 or more, convert extra inches into feet.
  5. Return the resulting distance.
  6. Display the result.

C++ Program

#include <iostream>

using namespace std;

class Distance
{
    int feet;
    int inches;

public:
    Distance(int f = 0, int i = 0)
    {
        feet = f;
        inches = i;
    }

    Distance operator+(const Distance &d)
    {
        Distance temp;

        temp.feet = feet + d.feet;
        temp.inches = inches + d.inches;

        if (temp.inches >= 12)
        {
            temp.feet += temp.inches / 12;
            temp.inches %= 12;
        }

        return temp;
    }

    void display()
    {
        cout << feet << " feet "
             << inches << " inches";
    }
};

int main()
{
    Distance d1(5, 8);
    Distance d2(3, 7);

    Distance d3 = d1 + d2;

    cout << "Total Distance: ";
    d3.display();

    return 0;
}

Expected Output

Total Distance: 9 feet 3 inches
VISUAL EXPLANATION

Unit Normalization

5' 8"Distance 1
+
3' 7"Distance 2
→
9' 3"Normalized result

Program Explanation

  • The + operator adds two Distance objects.
  • Feet and inches are added separately.
  • Every 12 inches are converted into one foot.
  • The normalized Distance object is returned.

Real-Life Connection

Engineering and measurement software can represent physical quantities as objects and support natural arithmetic expressions.

Key Points

  • Operator overloading improves object expression syntax.
  • Unit conversion may be necessary after arithmetic.
  • The overloaded operator should model a meaningful operation.

Common Errors

Conversion

Convert 12 or more inches into feet.

Remainder

Use the remainder for the final inches value.

Return Object

Return the calculated Distance object.

Wrong Operator

Use operator+ for the + operation.

TYPE 04

Virtual Function / Runtime Polymorphism

A virtual function allows a call through a base-class pointer or reference to execute the overridden function belonging to the actual derived object.

PROBLEM 04.1

Problem Statement

Write a C++ program to demonstrate runtime polymorphism using a virtual area() function in a base class Shape and derived classes Circle and Rectangle.

Theory / Concept

The base pointer refers to a derived object. Because area() is virtual, the correct derived implementation is selected at runtime.

SYNTAX

Virtual Function

class Base
{
public:
    virtual void display()
    {
    }
};

class Derived : public Base
{
public:

    }
};

  2. Derive Circle and Rectangle.
  3. Override area() in both classes.
  4. Create derived objects.
  5. Use a Shape pointer to refer to each object.
  6. Call area() through the base pointer.

Vehicle Start Using Virtual Function

Problem Statement

Write a C++ program to demonstrate runtime polymorphism using a virtual start() function in a base class Vehicle and derived classes Car and Bike.

Theory / Concept

Vehicle defines a common start operation. Car and Bike override it with their own behavior. A Vehicle pointer can invoke the correct derived function at runtime.

SYNTAX

Virtual start()

class Vehicle
{
public:
    virtual void start()
    {
    }
};

class Car : public Vehicle
{
public:
    void start() override
    {
    }
};

Algorithm

  1. Create Vehicle with virtual start().
  2. Derive Car and Bike.
  3. Override start() in both classes.
  4. Create Car and Bike objects.
  5. Use a Vehicle pointer.
  6. Point it to each derived object.
  7. Call start() and display the corresponding message.

C++ Program

    {

        cout << "Bike starts with a key/button" << endl;

{
    Car c;
    Bike b;

    Vehicle *ptr;

    ptr = &c;
    ptr->start();

    ptr = &b;

}

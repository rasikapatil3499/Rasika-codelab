03 — EXPLORE THE CONCEPT

Understanding Static Members

Static members are associated with the class itself and are shared among all objects of that class.

Theory

A static data member is a class variable that is shared by all objects of the class. Unlike ordinary data members, only one copy of a static data member exists for the entire class.

A static member function also belongs to the class rather than to a particular object. It can be called using the class name and the scope resolution operator.

Static member functions can directly access static data members of the class.

class Demo { static int count; public: static void show(); }; int Demo::count = 0; void Demo::show() { cout << count; }
Class → Static Member → Shared Data
🌍

Real-Life Example

Consider a college application where many Student objects are created. If the application needs to maintain the total number of students created, the count can be stored in a static data member.

Similarly, a static member function can provide a class-level operation to display or access that shared count.

Where & How Is It Used?

Object Counting

A static data member can maintain the number of objects created from a class.

Shared Information

Data that belongs to the class as a whole can be stored using a static data member.

Class-Level Operations

Static member functions can perform operations that do not require a particular object.

Basic Syntax 

class ClassName
{
    static int data;

public:
    static void function();
};

int ClassName::data = 0;

void ClassName::function()
{
    // function body
}
LLO 8.1

Static Data Member

Concept

A static data member is shared by all objects of a class. Only one copy of the static data member exists, regardless of how many objects are created.

It is declared inside the class and normally defined outside the class using the scope resolution operator.

PROBLEM 01

Count Number of Objects

Problem Statement

Write a C++ program to create a class Student with a static data member to count the number of Student objects created.

Algorithm

  1. Start.
  2. Create a Student class.
  3. Declare a static integer variable count.
  4. Define count outside the class.
  5. Increment count whenever an object is created.
  6. Create multiple Student objects.
  7. Display the number of objects.
  8. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Student
{
    static int count;

public:

    Student()
    {
        count++;
    }

    void displayCount()
    {
        cout << "Number of objects = "
             << count;
    }
};

int Student::count = 0;

int main()
{
    Student s1, s2, s3;

    s1.displayCount();

    return 0;
}

Expected Output 

Number of objects = 3
STATIC DATA VISUALIZATION

One Static Variable → All Objects

The static data member is shared by every Student object.

OBJECT 1 s1 count = 1
+
OBJECT 2 s2 count = 2
+
OBJECT 3 s3 count = 3

Program Explanation

  • count is declared as a static data member.
  • Only one copy of count exists for the Student class.
  • The constructor increments count whenever an object is created.
  • Three objects result in a count of 3.

Real-Life Connection

A college management system can use a static counter to maintain the total number of Student objects currently created by a program.

Key Points

  • Static data belongs to the class.
  • It is shared by all objects.
  • It is defined outside the class.

Common Errors

Missing Definition

Define the static data member outside the class.

Creating Separate Copies

Do not define the static variable as an ordinary object data member.

PROBLEM 02

Common College Name

Problem Statement

Write a C++ program to create a Student class having a static data member to store the common college name shared by all Student objects.

Algorithm

  1. Start.
  2. Define a Student class.
  3. Declare name as a normal data member.
  4. Declare college as a static data member.
  5. Define the static college member outside the class.
  6. Create multiple Student objects.
  7. Display student names and common college name.
  8. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Student
{
    string name;

    static string college;

public:

    Student(string n)
    {
        name = n;
    }

    void display()
    {
        cout << "Name = "
             << name << endl;

        cout << "College = "
             << college << endl;
    }
};

string Student::college =
    "Rasika College";

int main()
{
    Student s1("Rahul");
    Student s2("Priya");

    s1.display();
    cout << endl;
    s2.display();

    return 0;
}

Expected Output 

Name = Rahul
College = Rasika College

Name = Priya
College = Rasika College
STATIC DATA VISUALIZATION

Shared College Information

STUDENT 1 Rahul College → Rasika College
→
STATIC DATA College One Shared Copy
←
STUDENT 2 Priya College → Rasika College

Program Explanation

  • name belongs separately to each Student object.
  • college is static and shared by all Student objects.
  • Only one copy of the college name exists.
  • Both objects access the same static value.

Real-Life Connection

In a student management system, every student may belong to the same college. Storing the common college name as a static data member avoids maintaining separate copies.

Key Points

  • Static data is common to all objects.
  • Ordinary data members have separate copies.
  • Static data can be accessed by class scope.

Common Errors

Wrong Declaration

Use the static keyword when declaring the shared data member.

Missing Scope

Define the static member using Student::college.

PROBLEM 03

Bank Account Counter

Problem Statement

Write a C++ program to create a BankAccount class with a static data member that stores the total number of bank account objects created.

Algorithm

  1. Start.
  2. Define the BankAccount class.
  3. Declare a static variable accountCount.
  4. Define accountCount outside the class.
  5. Increment the counter when an account object is created.
  6. Create three account objects.
  7. Display the total account count.
  8. Stop.

C++ Program 

#include <iostream>
using namespace std;

class BankAccount
{
    static int accountCount;

public:

    BankAccount()
    {
        accountCount++;
    }

    void displayCount()
    {
        cout << "Total accounts = "
             << accountCount;
    }
};

int BankAccount::accountCount = 0;

int main()
{
    BankAccount a1;
    BankAccount a2;
    BankAccount a3;

    a1.displayCount();

    return 0;
}

Expected Output 

Total accounts = 3
STATIC DATA VISUALIZATION

Account Objects Share One Counter

ACCOUNT 1 a1 Count = 1
+
ACCOUNT 2 a2 Count = 2
+
ACCOUNT 3 a3 Count = 3

Program Explanation

  • accountCount is a static data member.
  • It is shared by all BankAccount objects.
  • The constructor increases the counter.
  • Three objects result in a count of 3.

Real-Life Connection

Banking software can maintain a class-level count of account objects created during the execution of an application.

Key Points

  • Static data is shared.
  • It has a single class-level copy.
  • It can maintain common information.

Common Errors

Not Initializing

Initialize the static counter before using it.

Incorrect Scope

Use BankAccount::accountCount for the external definition.

Static Member Function

Concept

A static member function belongs to the class rather than a particular object. It can be called using the class name and the scope resolution operator.

A static member function can directly access static data members because both belong to the class.

PROBLEM 01

Display Object Count

Problem Statement

Write a C++ program to create a class Student with a static data member and a static member function to display the number of objects created.

Algorithm

  1. Start.
  2. Define the Student class.
  3. Declare static variable count.
  4. Declare static function showCount().
  5. Define the static data member.
  6. Increment count in the constructor.
  7. Create Student objects.
  8. Call showCount() using the class name.
  9. Display the count.
  10. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Student
{
    static int count;

public:

    Student()
    {
        count++;
    }

    static void showCount()
    {
        cout << "Number of objects = "
             << count;
    }
};

int Student::count = 0;

int main()
{
    Student s1;
    Student s2;
    Student s3;

    Student::showCount();

    return 0;
}

Expected Output 

Number of objects = 3
STATIC FUNCTION VISUALIZATION

Class Name → Static Function → Shared Data

CLASS Student Class Scope
→
STATIC FUNCTION showCount() No object required
→
STATIC DATA count = 3 Shared value

Program Explanation

  • showCount() is declared as a static member function.
  • It accesses the static variable count.
  • It is called using Student::showCount().
  • No Student object is required to call the static member function.

Real-Life Connection

A student management application can provide a class-level operation to display the total number of Student objects without requiring a particular student object.

Key Points

  • Static functions belong to the class.
  • They can be called using the class name.
  • They can directly access static members.

Common Errors

Missing static

Use the static keyword in the function declaration.

Accessing Normal Data

A static member function cannot directly access non-static data members.

PROBLEM 02

Calculate Square Using Static Function

Problem Statement

Write a C++ program to create a class Calculator with a static member function to calculate the square of a given number.

Formula

Square Number × Number
Input 8
Output 64

Algorithm

  1. Start.
  2. Create a Calculator class.
  3. Declare a static function square().
  4. Accept a number.
  5. Call square() using the class name.
  6. Calculate the square.
  7. Display the result.
  8. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Calculator
{
public:

    static int square(int n)
    {
        return n * n;
    }
};

int main()
{
    int num;

    cout << "Enter a number: ";
    cin >> num;

    cout << "Square = "
         << Calculator::square(num);

    return 0;
}

Expected Output 

Enter a number: 8
Square = 64
STATIC FUNCTION VISUALIZATION

Class → Static Function → Result

INPUT 8 Number
→
STATIC FUNCTION square() Calculator::square()
→
OUTPUT 64 8 × 8

Program Explanation

  • square() is a static member function.
  • It does not require a Calculator object.
  • It is called using Calculator::square().
  • The function receives a number and returns its square.

Real-Life Connection

Utility calculations such as square, cube, conversion or validation can be implemented as class-level operations when they do not depend on individual object data.

Key Points

  • A static function can be called without creating an object.
  • It is accessed using the class name.
  • It is useful for class-level utility operations.

Common Errors

Wrong Call

Use Calculator::square() to call the static function.

Missing static

The function must be declared using the static keyword.

PROBLEM 03

Display Company Information

Problem Statement

Write a C++ program to create an Employee class containing a static data member for company name and a static member function to display the company information.

Algorithm

  1. Start.
  2. Create an Employee class.
  3. Declare company as a static data member.
  4. Declare showCompany() as a static member function.
  5. Define the static company variable.
  6. Define the static member function.
  7. Call showCompany() using the class name.
  8. Display company information.
  9. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Employee
{
    static string company;

public:

    static void showCompany()
    {

}

Expected Output 

Company = Tech Solutions
STATIC FUNCTION VISUALIZATION

Class-Level Information

CLASS Employee No object required
→
STATIC FUNCTION showCompany() Class-level operation

STATIC DATA Tech Solutions Shared company name

Program Explanation

  • company is a static data member.
  • showCompany() is a static member function.
  • The function can access the static company variable.

Real-Life Connection

In an employee management system, company information is common to all employees. A static member can store this common information and a static function can display it without requiring an employee object.

Key Points

  • Static functions belong to the class.
  • They can directly access static data members.
  • They can be called using the class name.

Common Errors

04 — VIVA QUESTIONS

Test Your Understanding

Static Data Member

What is a static data member?

A static data member is a class-level variable shared by all objects of the class.

How many copies of a static data member exist?

Only one copy exists for the entire class.

How is a static data member defined outside the class?

It is defined using the class name and scope resolution operator, for example Student::count = 0;.

Why is a static data member useful?

It is useful when data needs to be shared among all objects of a class.

Give one real-life use of a static data member.

A static counter can be used to maintain the number of objects or records created by a class.

Static Member Function

What is a static member function?

A static member function is a function that belongs to the class rather than a particular object.

How is a static member function called?

It can be called using the class name and scope resolution operator, such as Student::showCount().

Can a static member function access non-static data?

A static member function cannot directly access non-static data members because it does not have an object context.

What can a static member function directly access?

It can directly access static data members and other static member functions of the class.

Is an object required to call a static member function?

No. It can be called using the class name.

Static vs Non-Static

What is the main difference between static and non-static data members?

A non-static data member has a separate copy for each object, while a static data member has one shared copy for the entire class.

Can a static function be called using an object?

C++ permits calling a static member function through an object, but class-name syntax such as ClassName::function() clearly expresses that the function belongs to the class.

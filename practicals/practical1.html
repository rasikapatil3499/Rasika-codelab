PROBLEM 01

Simple Calculator

Problem Statement

Write a C++ program to develop a simple calculator that accepts two numbers from the user and performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

Operations

Addition a + b
Subtraction a - b
Multiplication a * b
Division a / b

Algorithm

  1. Start.
  2. Declare two variables.
  3. Accept two numbers using cin.
  4. Perform addition, subtraction, multiplication and division.
  5. Display the results using cout.
  6. Stop.

C++ Program 

#include <iostream>
using namespace std;

int main()
{
    float a, b;

    cout << "Enter first number: ";
    cin >> a;

    cout << "Enter second number: ";
    cin >> b;

    cout << "Addition = " << a + b << endl;
    cout << "Subtraction = " << a - b << endl;
    cout << "Multiplication = " << a * b << endl;

    if (b != 0)
        cout << "Division = " << a / b << endl;
    else
        cout << "Division is not possible." << endl;

    return 0;
}

Expected Output 

Enter first number: 20
Enter second number: 5

Addition = 25
Subtraction = 15
Multiplication = 100
Division = 4

Key Points

  • cin is used to accept input from the user.
  • cout is used to display output.
  • Arithmetic operators perform mathematical calculations.
  • Division by zero must be avoided.

Common Errors

Division by zero

Always check that the second number is not zero before division.

Wrong operator

Use * for multiplication, not ×.

CONCEPT

Understanding Pointers

What is a Pointer?

A pointer is a variable that stores the memory address of another variable or object.

int value = 25Actual data
←
int *ptrStores address
→
*ptrReads value 25
01

Address-of Operator &

The & operator obtains the memory address of a variable.

02

Dereference Operator *

The * operator accesses the value stored at the address held by a pointer.

03

Arrow Operator ->

The -> operator accesses members of an object through an object pointer.

04

Pointer Arithmetic

Adding to a typed pointer moves it by the size of its pointed-to type.

Real-Life Example

A pointer can be compared with an address written on a location card. The card does not contain the building itself; it tells you where the building is. Similarly, a pointer stores an address that lets the program reach the data at that location.

Where and How Are Pointers Used?

Functions

Pass addresses so functions can modify original variables or receive output through pointer parameters.

Arrays

Traverse arrays using pointer arithmetic and access elements through dereferencing.

Objects

Access class members using object pointers and the arrow operator.

Dynamic Memory

Create memory during runtime using new and release it using delete.

POINTER BASICS

Display Value and Address

Problem Statement

Write a C++ program to create a pointer to an integer variable and display the variable's value, its address, and the value stored in the pointer.

Theory / Concept

A pointer is a variable that stores the memory address of another variable. The address-of operator (&) obtains an address and the dereference operator (*) accesses the value stored at that address.

SYNTAX

Display Value and Address

int value = 10;
int *ptr = &value;

cout << value;
cout << &value;
cout << *ptr;

Algorithm

  1. Declare an integer variable.
  2. Declare an integer pointer.
  3. Store the address of the integer using &.
  4. Display the variable value and address.
  5. Dereference the pointer using * and display the value.

C++ Program

#include <iostream>
using namespace std;

int main()
{
    int value = 25;
    int *ptr = &value;

    cout << "Value: " << value << endl;
    cout << "Address: " << &value << endl;
    cout << "Value using pointer: " << *ptr << endl;

    return 0;
}

Expected Output

Value: 25
Address: 0x...
Value using pointer: 25
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

ptr stores the address of value. Dereferencing ptr gives the value stored at that address.

Program Explanation

  • A pointer stores an address.
  • & gives an address.
  • * dereferences a pointer.
  • The pointer type should match the pointed-to data type.

Real-Life Connection

Pointers are useful when a program needs direct access to a variable's memory location, such as in low-level programming and dynamic data structures.

Key Points

  • A pointer stores an address.
  • & gives an address.
  • * dereferences a pointer.
  • The pointer type should match the pointed-to data type.

Common Errors

Uninitialized pointer

Always initialize a pointer before dereferencing it.

Wrong type

Use a compatible pointer type, such as int* for an int.

Confusing & and *

& obtains an address; * accesses the value at an address.

POINTER BASICS

Swap Two Numbers Using Pointers

Problem Statement

Write a C++ program to swap two numbers using pointers and a function.

Theory / Concept

When addresses are passed to a function, the function can modify the original variables through dereferencing. This is a practical use of pass-by-address.

SYNTAX

Swap Two Numbers Using Pointers

void swapNumbers(int *a, int *b)
{
    // use *a and *b
}

Algorithm

  1. Declare two integer variables.
  2. Pass their addresses to swapNumbers().
  3. Store the first value in a temporary variable.
  4. Assign the second value to the first.
  5. Assign the temporary value to the second.
  6. Display the swapped values.

C++ Program

#include <iostream>
using namespace std;

void swapNumbers(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main()
{
    int x = 10, y = 20;

    swapNumbers(&x, &y);

    cout << "After swapping: " << x << " " << y;

    return 0;
}

Expected Output

After swapping: 20 10
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

main() sends &x and &y. The function receives their addresses, and *a and *b modify the original variables.

Program Explanation

  • Pass addresses using &.
  • Dereference parameters using *.
  • Changes through the pointer affect the original variables.

Real-Life Connection

Functions can use addresses to update original data, which is useful in operations such as swapping, sorting and modifying multiple values.

Key Points

  • Pass addresses using &.
  • Dereference parameters using *.
  • Changes through the pointer affect the original variables.

Common Errors

Passing values

Pass &x and &y when the function expects pointers.

Missing dereference

Use *a and *b to access the original values.

Wrong temporary logic

Store one value before overwriting it.

POINTER BASICS

Access Array Elements Using Pointer

Problem Statement

Write a C++ program to access and display array elements using a pointer.

Theory / Concept

The name of an array represents the address of its first element in most expressions. A pointer can move through the array using pointer arithmetic.

SYNTAX

Access Array Elements Using Pointer

int arr[5] = {10, 20, 30, 40, 50};
int *ptr = arr;

cout << *(ptr + i);

Algorithm

  1. Create an integer array.
  2. Declare a pointer and assign the array's first-element address.
  3. Use pointer arithmetic to move through the array.
  4. Dereference the pointer at each position.
  5. Display all elements.

C++ Program

#include <iostream>
using namespace std;

int main()
{
    int arr[5] = {10, 20, 30, 40, 50};
    int *ptr = arr;

    for (int i = 0; i < 5; i++)
    {
        cout << *(ptr + i) << " ";
    }

    return 0;
}

Expected Output

10 20 30 40 50
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

ptr points to arr[0]. ptr + 1 points to the next integer element, so *(ptr + i) accesses arr[i].

Program Explanation

  • Array name gives the first-element address in this context.
  • ptr+i moves by i elements, not i bytes.
  • *(ptr+i) accesses the element.

Real-Life Connection

Pointers are commonly used to traverse arrays efficiently and form the basis of many data structures and algorithms.

Key Points

  • Array name gives the first-element address in this context.
  • ptr+i moves by i elements, not i bytes.
  • *(ptr+i) accesses the element.

Common Errors

Out of bounds

Only access valid array indexes.

Wrong arithmetic

Use pointer arithmetic according to the pointer's type.

Missing *

ptr+i is an address; *(ptr+i) is the value.

POINTER AND FUNCTIONS

Pass by Address

Problem Statement

Write a C++ program to modify the value of a variable using a pointer parameter.

Theory / Concept

Pass-by-address allows a function to receive the memory address of a variable and modify the original data through a pointer.

SYNTAX

Pass by Address

void update(int *ptr)
{
    *ptr = 100;
}

update(&value);

Algorithm

  1. Declare a variable.
  2. Create a function with an int pointer parameter.
  3. Pass the variable's address.
  4. Dereference the pointer inside the function.
  5. Display the modified value.

C++ Program

#include <iostream>
using namespace std;

void update(int *ptr)
{
    *ptr = 100;
}

int main()
{
    int value = 25;

    update(&value);

    cout << "Updated value: " << value;

    return 0;
}

Expected Output

Updated value: 100
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

The function receives the address of value. Assigning to *ptr changes the original variable.

Program Explanation

  • Pointer parameters receive addresses.
  • Use & at the call site.
  • Use * inside the function to modify the value.

Real-Life Connection

Pass-by-address is useful when a function must change caller-owned data.

Key Points

  • Pointer parameters receive addresses.
  • Use & at the call site.
  • Use * inside the function to modify the value.

Common Errors

Passing value instead of address

Call update(&value).

Dereferencing null

Never dereference a null pointer.

Wrong parameter type

Use a pointer type compatible with the argument.

POINTER AND FUNCTIONS

Return Value Through Pointer

Problem Statement

Write a C++ program to calculate the sum of two numbers and store the result in a variable supplied through a pointer.

Theory / Concept

A pointer parameter can be used as an output parameter. The function writes its result into the memory location supplied by the caller.

SYNTAX

Return Value Through Pointer

void calculate(int a, int b, int *result)
{
    *result = a + b;
}

Algorithm

  1. Declare two numbers and a result variable.
  2. Pass the two numbers and address of result.
  3. Calculate the sum.
  4. Store the result using *result.
  5. Display the result.

C++ Program

#include <iostream>
using namespace std;

void calculate(int a, int b, int *result)
{
    *result = a + b;
}

int main()
{
    int a = 15, b = 25;
    int result;

    calculate(a, b, &result);

    cout << "Sum: " << result;

    return 0;
}

Expected Output

Sum: 40
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

result is supplied by address. The function writes 40 into that memory location.

Program Explanation

  • Pass &result.
  • Assign through *result.
  • The result variable exists in main().

Real-Life Connection

Output parameters are useful when a function needs to return calculated data through caller-provided storage.

Key Points

  • Pass &result.
  • Assign through *result.
  • The result variable exists in main().

Common Errors

Uninitialized output use

Assign to *result before reading result.

Missing &

Pass the address of the output variable.

Wrong pointer

The result parameter must be int*.

POINTER AND FUNCTIONS

Function with Pointer Parameters

Problem Statement

Write a C++ program to find the larger of two numbers using a function that accepts pointer parameters.

Theory / Concept

Pointer parameters allow the function to read values indirectly from the addresses passed by the caller.

SYNTAX

Function with Pointer Parameters

int larger(int *a, int *b)
{
    return (*a > *b) ? *a : *b;
}

Algorithm

  1. Declare two integers.
  2. Pass their addresses to the function.
  3. Dereference both pointers.
  4. Compare the values.
  5. Return the larger value.
  6. Display it.

C++ Program

#include <iostream>
using namespace std;

int larger(int *a, int *b)
{
    return (*a > *b) ? *a : *b;
}

int main()
{
    int x = 45, y = 32;

    cout << "Larger value: "
         << larger(&x, &y);

    return 0;
}

Expected Output

Larger value: 45
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

The function receives addresses, dereferences them and compares the original values.

Program Explanation

  • Pass addresses.
  • Dereference before comparison.
  • The function returns the selected value.

Real-Life Connection

Pointer parameters can provide a common interface for functions that operate directly on memory locations.

Key Points

  • Pass addresses.
  • Dereference before comparison.
  • The function returns the selected value.

Common Errors

Comparing addresses

Compare *a and *b, not a and b.

Wrong call

Use larger(&x, &y).

Missing return

Return the larger value.

POINTER AND OBJECTS

Pointer to Object

Problem Statement

Write a C++ program to create an object and a pointer to that object, then access a member function through the pointer.

Theory / Concept

A pointer can store the address of a class object. The arrow operator (->) is used to access members through an object pointer.

SYNTAX

Pointer to Object

ClassName obj;
ClassName *ptr = &obj;

ptr->function();

Algorithm

  1. Create a class with a member function.
  2. Create an object.
  3. Create a pointer to the object.
  4. Store the object's address in the pointer.
  5. Call the member function using ->.

C++ Program

#include <iostream>
using namespace std;

class Student
{
public:
    void display()
    {
        cout << "Student object accessed using pointer";
    }
};

int main()
{
    Student obj;
    Student *ptr = &obj;

    ptr->display();

    return 0;
}

Expected Output

Student object accessed using pointer
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

ptr stores the address of obj. ptr->display() accesses the member function through that address.

Program Explanation

  • Use ClassName* for an object pointer.
  • Store the object's address using &.
  • Use -> to access members through a pointer.

Real-Life Connection

Pointers to objects are useful when working with dynamically created objects and polymorphic class hierarchies.

Key Points

  • Use ClassName* for an object pointer.
  • Store the object's address using &.
  • Use -> to access members through a pointer.

Common Errors

Using . with pointer

Use -> when the variable is an object pointer.

Uninitialized pointer

Assign a valid object address first.

Wrong class type

The pointer should point to a compatible object.

POINTER AND OBJECTS

Access Members Using ->

Problem Statement

Write a C++ program to create an Employee object and access its data members and member function using an object pointer.

Theory / Concept

The arrow operator provides member access through a pointer. It is equivalent to dereferencing the pointer and then using the dot operator.

SYNTAX

Access Members Using ->

Employee *ptr = &emp;

ptr->id;
ptr->display();

Algorithm

  1. Define Employee with id and name.
  2. Create an Employee object.
  3. Create an Employee pointer.
  4. Assign the object's address.
  5. Access members using ->.
  6. Display the details.

C++ Program

#include <iostream>
#include <string>
using namespace std;

class Employee
{
public:
    int id;
    string name;

    void display()
    {
        cout << "ID: " << id << endl;
        cout << "Name: " << name;
    }
};

int main()
{
    Employee emp;
    emp.id = 101;
    emp.name = "Asha";

    Employee *ptr = &emp;

    cout << "ID through pointer: " << ptr->id << endl;
    cout << "Name through pointer: " << ptr->name << endl;

    ptr->display();

    return 0;
}

Expected Output

ID through pointer: 101
Name through pointer: Asha
ID: 101
Name: Asha
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

ptr points to emp. The -> operator accesses id, name and display() through the pointer.

Program Explanation

  • obj.member uses an object.
  • ptr->member uses an object pointer.
  • -> combines dereferencing and member access.

Real-Life Connection

Object pointers are useful in applications that manage collections of objects or dynamically allocated class instances.

Key Points

  • obj.member uses an object.
  • ptr->member uses an object pointer.
  • -> combines dereferencing and member access.

Common Errors

Using .

Use -> for a pointer.

Missing string header

Include <string> when using string.

Invalid address

Point to a valid Employee object.

POINTER AND OBJECTS

Array of Objects Using Pointer

Problem Statement

Write a C++ program to create an array of Student objects and access each object using a pointer.

Theory / Concept

A pointer can point to the first object in an array. Incrementing the pointer moves it to the next object because pointer arithmetic uses the size of the pointed-to type.

SYNTAX

Array of Objects Using Pointer

Student obj[3];
Student *ptr = obj;

(ptr + i)->display();

Algorithm

  1. Create an array of Student objects.
  2. Point a Student pointer to the first object.
  3. Use pointer arithmetic to reach each object.
  4. Use -> to call the member function.
  5. Display all student details.

C++ Program

#include <iostream>
using namespace std;

class Student
{
    int rollNo;

public:
    Student(int r = 0)
    {
        rollNo = r;
    }

    void display()
    {
        cout << "Roll No: " << rollNo << endl;
    }
};

int main()
{
    Student obj[3] = {Student(101), Student(102), Student(103)};
    Student *ptr = obj;

    for (int i = 0; i < 3; i++)
    {
        (ptr + i)->display();
    }

    return 0;
}

Expected Output

Roll No: 101
Roll No: 102
Roll No: 103
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

ptr starts at obj[0]. ptr+1 points to obj[1], and so on. The -> operator accesses each object's member function.

Program Explanation

  • Pointer arithmetic advances by object size.
  • Use (ptr+i)->member for the i-th object.
  • The pointer should point to the first array element.

Real-Life Connection

Arrays of objects with pointers are useful when processing many records sequentially.

Key Points

  • Pointer arithmetic advances by object size.
  • Use (ptr+i)->member for the i-th object.
  • The pointer should point to the first array element.

Common Errors

Wrong increment

Use ptr+i for the i-th object.

Out of bounds

Stay within the array size.

Operator precedence

Use parentheses around ptr+i before -> when needed.

TOPIC 04

Dynamic Memory

Allocate and release memory during program execution using new and delete.

DYNAMIC MEMORY

Dynamic Integer

Problem Statement

Write a C++ program to allocate memory dynamically for one integer, assign a value, display it and release the memory.

Theory / Concept

Dynamic memory is allocated during program execution using new. The allocated memory should be released using delete when it is no longer needed.

SYNTAX

Dynamic Integer

int *ptr = new int;

*ptr = 50;

delete ptr;

Algorithm

  1. Declare an integer pointer.
  2. Allocate memory using new.
  3. Store a value using dereferencing.
  4. Display the value.
  5. Release the allocated memory using delete.
  6. Set the pointer to nullptr after deletion if it will be reused.

C++ Program

#include <iostream>
using namespace std;

int main()
{
    int *ptr = new int;

    *ptr = 50;

    cout << "Dynamic value: " << *ptr << endl;

    delete ptr;
    ptr = nullptr;

    return 0;
}

Expected Output

Dynamic value: 50
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

new allocates an integer on the free store and returns its address. delete releases that memory.

Program Explanation

  • new allocates memory.
  • delete releases a single dynamically allocated object.
  • Do not use a pointer after deleting its target.
  • nullptr represents no valid object.

Real-Life Connection

Dynamic allocation is useful when the amount of memory needed is determined during program execution.

Key Points

  • new allocates memory.
  • delete releases a single dynamically allocated object.
  • Do not use a pointer after deleting its target.
  • nullptr represents no valid object.

Common Errors

Memory leak

Release dynamically allocated memory.

delete[] mismatch

Use delete for one object allocated with new.

Use-after-delete

Do not dereference a pointer after delete.

DYNAMIC MEMORY

Dynamic Array

Problem Statement

Write a C++ program to dynamically allocate an integer array, accept values, display them and release the memory.

Theory / Concept

The new[] operator allocates an array dynamically. The corresponding delete[] operator must be used to release that array.

SYNTAX

Dynamic Array

int *arr = new int[n];

delete[] arr;

Algorithm

  1. Accept the array size.
  2. Allocate n integers using new[].
  3. Accept values through the pointer.
  4. Display the elements.
  5. Release the array using delete[].

C++ Program

#include <iostream>
using namespace std;

int main()
{
    int n;

    cout << "Enter size: ";
    cin >> n;

    int *arr = new int[n];

    for (int i = 0; i < n; i++)
        cin >> arr[i];

    cout << "Array: ";

    for (int i = 0; i < n; i++)
        cout << arr[i] << " ";

    delete[] arr;
    arr = nullptr;

    return 0;
}

Expected Output

Enter size: 3
10 20 30
Array: 10 20 30
VISUAL EXPLANATION

How the Pointer Works

Variable / ObjectStores actual data
←
PointerStores its address
→
Dereference *Accesses the data

arr points to the first element of a dynamically allocated array. arr[i] accesses each element.

Program Explanation

  • Use new[] for dynamic arrays.
  • Use delete[] for memory allocated with new[].
  • Check the size before allocating and accessing memory.

Real-Life Connection

Dynamic arrays are useful when the required collection size is known only at runtime.

Key Points

  • Use new[] for dynamic arrays.
  • Use delete[] for memory allocated with new[].
  • Check the size before allocating and accessing memory.

Common Errors

Using delete

Use delete[] for an array.

Out of bounds

Access only indexes 0 to n-1.

Invalid size

Do not allocate an invalid or unintended size.

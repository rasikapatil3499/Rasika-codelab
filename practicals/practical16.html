CONCEPT

Understanding Exception Handling

What is an Exception?

An exception is an unusual condition that occurs while a program is executing and prevents the normal flow of the operation. Exception handling provides a structured way to detect and handle such conditions.

01

try

Contains the code where an exceptional condition may occur.

02

throw

Signals that an exceptional condition has occurred.

03

catch

Receives and handles an exception thrown from a try block.

04

Exception Class

A standard or user-defined type can carry information about the error.

Real-Life Example

Consider an ATM. A withdrawal greater than the available balance is not a normal transaction. Instead of continuing with the transaction, the system detects the exceptional condition and shows an appropriate message. C++ exception handling provides a structured mechanism for similar situations.

Where and How Is It Used?

Input Validation

Handle values that violate application rules.

Financial Operations

Handle conditions such as insufficient balance or invalid transactions.

Array / Container Access

Handle invalid indexes using bounds-checked operations and standard exceptions.

Runtime Failures

Represent failures detected during execution using suitable standard exception classes.

PROBLEM

Divide by Zero

Problem Statement

Write a C++ program to divide two numbers and throw an exception when the denominator is zero.

Theory / Concept

Exception handling separates error-handling code from normal program logic. A risky operation is placed inside try, an error is reported using throw, and the matching catch block handles it.

SYNTAX

Exception Handling Syntax

try
{
    // risky code
    if (b == 0)
        throw b;
}
catch (int)
{
    // handle exception
}

Algorithm

  1. Accept two numbers.
  2. Start the try block.
  3. Check whether the denominator is zero.
  4. Throw an exception if it is zero.
  5. Otherwise perform division.
  6. Handle the exception in catch.
  7. Display the result or error message.

C++ Program

#include <iostream>
using namespace std;

int main()
{
    int a = 20, b = 0;

    try
    {
        if (b == 0)
            throw b;

        cout << "Result: " << a / b;
    }
    catch (int)
    {
        cout << "Error: Division by zero is not allowed.";
    }

    return 0;
}

Expected Output

Error: Division by zero is not allowed.

Real-Life Connection

Division by zero can occur in calculators, billing systems and mathematical applications. Exception handling prevents the invalid operation from being processed normally.

SYNTAX

Exception Handling Syntax

class InvalidMarks
{
public:
    string message;
    InvalidMarks(string msg) : message(msg) {}
};

throw InvalidMarks("Invalid marks");

Algorithm

  1. Create a custom exception class.
  2. Accept or assign marks.
  3. Check the range.
  4. Throw an InvalidMarks object when the range is invalid.
  5. Catch the custom exception.
  6. Display its message.

C++ Program

#include <iostream>
#include <string>
using namespace std;

class InvalidMarks
{
public:
    string message;

    InvalidMarks(string msg)
    {
        message = msg;
    }
};

int main()
{
    int marks = 125;

    try
    {
        if (marks < 0 || marks > 100)

        cout << "Valid marks.";
    }
    catch (InvalidMarks e)
    {
        cout << "Error: " << e.message;
    }

    return 0;

Theory / Concept

SYNTAX

Exception Handling Syntax

class InsufficientBalance
{
public:
    string message;
    InsufficientBalance(string msg) : message(msg) {}
};

    throw InsufficientBalance("Insufficient balance");

Algorithm

  1. Set the account balance and withdrawal amount.
  2. Check whether the withdrawal exceeds the balance.
  3. Throw InsufficientBalance if it does.
  4. Catch the custom exception.
  5. Otherwise subtract the amount and display the balance.

C++ Program

#include <iostream>
#include <string>
using namespace std;

class InsufficientBalance
{
public:
    string message;

    InsufficientBalance(string msg)
    {
        message = msg;
    }
};

int main()
{
    double balance = 5000;
    double amount = 7000;

    try
    {
        if (amount > balance)
            throw InsufficientBalance("Insufficient balance.");

        balance -= amount;
        cout << "Remaining balance: " << balance;
    }
    catch (InsufficientBalance e)
    {
        cout << "Error: " << e.message;
    }

    return 0;
}

PROBLEM

out_of_range — Array Access

Problem Statement

Write a C++ program using the standard out_of_range exception to handle an invalid array/vector index.

Theory / Concept

Standard exception classes are provided by the C++ library. out_of_range represents an attempt to access an element outside an allowed range. vector::at() performs bounds checking and can throw it.

SYNTAX

Exception Handling Syntax

vector<int> values = {10, 20, 30};

try
{
    cout << values.at(index);
}
catch (const out_of_range &e)
{
    cout << e.what();
}

Algorithm

  1. Create a vector.
  2. Choose an invalid index.
  3. Use at() to access the element.
  4. Catch out_of_range.
  5. Display the exception message.

C++ Program

#include <iostream>
#include <vector>
#include <stdexcept>
using namespace std;

int main()
{
    vector<int> values = {10, 20, 30};
    int index = 5;

    try
    {
        cout << "Value: " << values.at(index);
    }
    catch (const out_of_range &e)
    {
        cout << "Error: " << e.what();
    }

    return 0;
}

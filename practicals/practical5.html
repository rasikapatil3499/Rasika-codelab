03 — EXPLORE THE CONCEPT

Defining Functions Outside the Class

Learn how a member function can be declared inside a class and its complete definition can be written outside the class.

Theory

In C++, a member function can be declared inside a class and defined separately outside the class. The function declaration remains inside the class, while its complete definition is written outside the class body.

The scope resolution operator :: is used to specify that the function belongs to a particular class.

For example, if display() is declared inside the Student class, it can be defined outside as:

void Student::display() { // function body }
Declaration → Class → Definition Outside
🌍

Real-Life Example

Consider a large college management application. The Student class may contain declarations of many functions, while the detailed implementation of those functions can be written separately. This keeps the class declaration easier to read and organize.

Where & How Is It Used?

Large Programs

Separating declarations and definitions makes large programs easier to organize.

Class Design

The class can show its interface while implementation details are written separately.

Reusable Code

Separating implementation from the class declaration supports better program structure.

Basic Syntax 

class ClassName
{
public:

    returnType functionName();
};


returnType ClassName::functionName()
{
    // function definition
}
PROBLEM 01

Student Details

Problem Statement

Write a C++ program to create a class Student with data members roll number and name. Declare member functions inside the class and define them outside the class to accept and display student details.

Algorithm

  1. Start.
  2. Define a class named Student.
  3. Declare roll number and name as data members.
  4. Declare accept() and display() functions inside the class.
  5. Define accept() outside the class using the scope resolution operator.
  6. Define display() outside the class using the scope resolution operator.
  7. Create an object of Student.
  8. Call the member functions using the object.
  9. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Student
{
    int rollNo;
    string name;

public:

    void accept();
    void display();
};


void Student::accept()
{
    cout << "Enter roll number: ";
    cin >> rollNo;

    cout << "Enter name: ";
    cin >> name;
}


void Student::display()
{
    cout << "\nRoll Number = "
         << rollNo << endl;

    cout << "Name = "
         << name;
}


int main()
{
    Student s;

    s.accept();
    s.display();

    return 0;
}

Expected Output 

Enter roll number: 101
Enter name: Rahul

Roll Number = 101
Name = Rahul
FUNCTION VISUALIZATION

Declaration → Definition → Object Call

The function is declared inside the class and its implementation is written outside using ::.

CLASS Student void accept(); void display();
→
OUTSIDE CLASS Student::display() Function Definition
→
OBJECT s s.display();

Program Explanation

  • Student is the class.
  • accept() and display() are declared inside the class.
  • Their definitions are written outside the class.
  • Student::display() specifies that display belongs to the Student class.
  • The object s calls the member functions using the dot operator.

Real-Life Connection

In a college management system, the class declaration can describe student operations while the detailed implementation of those operations can be maintained separately.

Key Points

  • The function declaration is written inside the class.
  • The function definition is written outside the class.
  • The scope resolution operator connects the function definition to its class.

Common Errors

Missing ::

Use Student::functionName() when defining the function outside the class.

Wrong Declaration

The function declaration and definition should have matching return types and parameters.

PROBLEM 02

Rectangle Area and Perimeter

Problem Statement

Write a C++ program to create a class Rectangle with data members length and breadth. Declare functions inside the class and define the functions outside the class to calculate and display the area and perimeter.

Formula

Area length × breadth
Perimeter 2 × (length + breadth)

Algorithm

  1. Start.
  2. Define a Rectangle class.
  3. Declare length and breadth.
  4. Declare accept() and calculate() inside the class.
  5. Define the functions outside the class using the scope resolution operator.
  6. Create a Rectangle object.
  7. Call the functions using the object.
  8. Display area and perimeter.
  9. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Rectangle
{
    float length;
    float breadth;

public:

    void accept();
    void calculate();
};


void Rectangle::accept()
{
    cout << "Enter length: ";
    cin >> length;

    cout << "Enter breadth: ";
    cin >> breadth;
}


void Rectangle::calculate()
{
    float area = length * breadth;

    float perimeter =
        2 * (length + breadth);

    cout << "\nArea = "
         << area << endl;

    cout << "Perimeter = "
         << perimeter;
}


int main()
{
    Rectangle r;

    r.accept();
    r.calculate();

    return 0;
}

Expected Output 

Enter length: 10
Enter breadth: 5

Area = 50
Perimeter = 30
FUNCTION VISUALIZATION

Rectangle Class

10 5
r length = 10 breadth = 5 r.calculate()
→
OUTSIDE CLASS Rectangle::calculate() Area & Perimeter

Program Explanation

  • Rectangle contains the dimensions and function declarations.
  • accept() is defined outside the class using Rectangle::.
  • calculate() is also defined outside the class.
  • The object r calls both functions.

Real-Life Connection

Engineering and graphics applications can represent shapes using classes and keep their calculation functions separately implemented for better organization.

Key Points

  • Function declarations remain inside the class.
  • Function implementations can be written outside the class.
  • The scope resolution operator identifies the class to which the function belongs.

Common Errors

Incorrect Scope

Use the correct class name before the scope resolution operator.

Function Mismatch

The outside definition must match the function declaration inside the class.

PROBLEM 03

Employee Salary

Problem Statement

Write a C++ program to create a class Employee with data members employee ID, name and basic salary. Declare member functions inside the class and define them outside the class to accept employee details and calculate the gross salary.

Algorithm

  1. Start.
  2. Define the Employee class.
  3. Declare employee ID, name and basic salary.
  4. Declare accept() and display() functions inside the class.
  5. Define the functions outside the class using the scope resolution operator.
  6. Create an Employee object.
  7. Accept employee details.
  8. Calculate and display gross salary.
  9. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Employee
{
    int empId;
    string name;
    float basicSalary;

public:

    void accept();
    void display();
};


void Employee::accept()
{
    cout << "Enter employee ID: ";
    cin >> empId;

    cout << "Enter name: ";
    cin >> name;

    cout << "Enter basic salary: ";
    cin >> basicSalary;
}


void Employee::display()
{
    float hra = basicSalary * 0.20;
    float da = basicSalary * 0.10;

    float grossSalary =
        basicSalary + hra + da;

    cout << "\nEmployee ID = "
         << empId << endl;

    cout << "Name = "
         << name << endl;

    cout << "Basic Salary = "
         << basicSalary << endl;

    cout << "Gross Salary = "
         << grossSalary;
}


int main()
{
    Employee e;

    e.accept();
    e.display();

    return 0;
}

Expected Output 

Enter employee ID: 101
Enter name: Amit
Enter basic salary: 30000

Employee ID = 101
Name = Amit
Basic Salary = 30000
Gross Salary = 39000
CLASS VISUALIZATION

Employee Object & Outside Function

OBJECT e
ID → 101 Name → Amit Salary → ₹30,000
→
OUTSIDE CLASS Employee::display() Calculates gross salary

Program Explanation

  • Employee is the class containing employee data.
  • accept() and display() are declared inside the class.
  • Their definitions are written outside the class.
  • Employee::display() identifies the function as a member of the Employee class.
  • The object e calls the member functions.

Real-Life Connection

Payroll software can use an Employee class to store employee information while keeping salary calculation functions separately implemented outside the class declaration.

Key Points

  • Class declarations can be kept concise.
  • Function implementation can be separated from the class declaration.
  • The scope resolution operator associates the outside function definition with its class.

Common Errors

Forgetting Class Name

The outside definition must use the class name followed by ::.

Declaration Mismatch

Return type, function name and parameters must match the declaration.

04 — VIVA QUESTIONS

Test Your Understanding

Functions Outside Class

Can a member function be defined outside a class?

Yes. A member function can be declared inside the class and defined outside using the scope resolution operator.

Which operator is used to define a member function outside the class?

The scope resolution operator :: is used.

What is the syntax for defining a function outside a class?

The syntax is returnType ClassName::functionName() followed by the function body.

Why are functions defined outside the class?

Separating the declaration from the implementation can make class definitions easier to read and larger programs easier to organize.

Classes & Objects

What is a class?

A class is a user-defined data type that groups related data and functions.

What is an object?

An object is an instance of a class.

How is an outside member function called?

It is called through an object using the dot operator, for example s.display().

What is the difference between declaration and definition?

A declaration specifies the function's name, return type and parameters, while a definition contains the actual implementation of the function.

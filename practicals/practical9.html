CONCEPT

Understanding Array of Objects

What is an Array of Objects?

An array of objects is a collection of objects belonging to the same class. Instead of creating each object separately, we can create multiple objects using a single array declaration.

Each element of the array represents one complete object and contains its own copy of the class data members. 

class Student
{
    int rollNo;
    string name;
};

Student s[3];

Here, s[0], s[1] and s[2] are three different Student objects.

Real-Life Example

Consider a college class containing 50 students. Every student has information such as roll number, name and marks.

Creating 50 separate variables would be difficult to manage. Instead, we can create an array of Student objects: 

Student students[50];

Each array element represents one student's complete record.

Where & How Is It Used?

  • Student Management: Store records of multiple students.
  • Employee Management: Store details of employees in an organization.
  • Library Systems: Store information about multiple books.
  • Banking Systems: Store multiple customer or account objects.
  • Inventory Systems: Store multiple product objects.

Basic Syntax 

class ClassName
{
    // data members
    // member functions
};

ClassName object[size];

To access an individual object: 

object[index].function();

PROBLEM 01

Student Details Using Array of Objects

Problem Statement

Write a C++ program to create a class Student containing roll number, name and marks. Create an array of three Student objects, accept their details and display all student records.

Algorithm

  1. Start the program.
  2. Define a class named Student.
  3. Declare roll number, name and marks as data members.
  4. Define member functions to accept and display details.
  5. Create an array of three Student objects.
  6. Use a loop to accept details of all students.
  7. Use another loop to display all student records.
  8. Stop the program.

C++ Program 

#include <iostream>
#include <string>

using namespace std;

class Student
{
    int rollNo;
    string name;
    float marks;

public:

    void accept()
    {
        cout << "Enter Roll No: ";
        cin >> rollNo;

        cout << "Enter Name: ";
        cin >> name;

        cout << "Enter Marks: ";
        cin >> marks;
    }

    void display()
    {
        cout << rollNo << "\t"
             << name << "\t"
             << marks << endl;
    }
};

int main()
{
    Student s[3];

    cout << "Enter details of 3 students\n";

    for(int i = 0; i < 3; i++)
    {
        cout << "\nStudent " << i + 1 << endl;

        s[i].accept();
    }

    cout << "\nStudent Details\n";

    for(int i = 0; i < 3; i++)
    {
        s[i].display();
    }

    return 0;
}

Program Explanation

  • Student s[3] creates three Student objects.
  • s[i].accept() calls the accept function for each object.
  • s[i].display() displays the data stored in each object.
  • The loop allows the same function to process every object.

Real-Life Connection

A college management system can store the details of many students using an array of Student objects. Each object represents one student's complete record.

Key Points

  • All objects belong to the same class.
  • Array indexing starts from 0.
  • Each object has its own copy of non-static data members.
  • Member functions are called using the specific array element.

Common Errors

Wrong Array Size

Make sure the array size matches the number of objects required.

Wrong Index

Remember that array indexing starts from 0.

Missing Object Access

Use object[index].function() to call a member function.

Loop Condition

Ensure the loop does not access an index outside the array.

PROBLEM 02

Employee Details Using Array of Objects

Problem Statement

Write a C++ program to create a class Employee containing employee ID, name and salary. Create an array of three Employee objects, accept employee details and display all records.

Algorithm

  1. Start the program.
  2. Define the Employee class.

#include <iostream>

    for(int i = 0; i < 3; i++)

    }

PROBLEM 03

Book Details Using Array of Objects

Problem Statement

Write a C++ program to create a class Book containing book ID, title and price. Create an array of three Book objects, accept book details and display all book records.

Algorithm

  1. Start the program.
  2. Define the Book class.
  3. Declare book ID, title and price.
  4. Define member functions for input and output.
  5. Create an array of three Book objects.
  6. Accept details of each book using a loop.
  7. Display all book records using a loop.
  8. Stop the program.

C++ Program 

#include <iostream>
#include <string>

using namespace std;

class Book
{
    int bookId;
    string title;
    float price;

public:

    void accept()
    {
        cout << "Enter Book ID: ";
        cin >> bookId;

        cout << "Enter Title: ";
        cin >> title;

        cout << "Enter Price: ";
        cin >> price;
    }

    void display()
    {
        cout << bookId << "\t"
             << title << "\t"
             << price << endl;
    }
};

int main()
{
    Book b[3];

    cout << "Enter details of 3 books\n";

    for(int i = 0; i < 3; i++)
    {
        cout << "\nBook " << i + 1 << endl;

        b[i].accept();
    }

    cout << "\nBook Details\n";

    for(int i = 0; i < 3; i++)
    {
        b[i].display();
    }

    return 0;
}

Program Explanation

  • b[i].display() displays the corresponding book record.

Real-Life Connection

A library system may contain thousands of books. Each book can be represented as an object, while an array of objects can be used in a basic program to manage multiple book records.

Key Points

  • An array can contain objects just like it contains primitive data values.
  • Every object has its own data members.
  • The dot operator is used to access member functions.
  • Loops are commonly used to process arrays of objects.

Common Errors

Wrong Object Name

Use the correct array name while accessing its elements.

Array Out of Bounds

For three objects, valid indexes are 0, 1 and 2.

Missing Class Definition

Define the class before creating its objects.

Incorrect Loop

Ensure the loop processes every object exactly once.

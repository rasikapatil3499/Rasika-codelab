CONCEPT

Understanding Inheritance

What is Inheritance?

Inheritance is an object-oriented programming mechanism in which a new class, called the derived class, acquires accessible properties and member functions of an existing class, called the base class.

It promotes code reusability and allows a derived class to add its own features to the inherited functionality.

Real-Life Example

Consider an organization. An employee has common information such as employee ID and name. A manager may use that common information and also have additional manager-specific information.

Inheritance models this relationship by allowing the derived class to reuse common features from the base class.

Where & How Is It Used?

  • Employee Systems: Reuse common employee information in Manager, Developer and other classes.
  • Education Systems: Extend Student information into Marks and Result classes.
  • Vehicle Systems: Extend common Vehicle features into Car, Bike or ElectricCar classes.
  • Banking Systems: Share common Account features among different account types.
  • Software Design: Build specialized classes from general-purpose classes.

Access Specifiers in Inheritance

public

Public members of the base class remain public in the derived class when public inheritance is used.

protected

Protected members can be accessed inside the derived class but are not directly accessible from outside.

private

Private members of a base class cannot be accessed directly by the derived class.

PROBLEM 01.1

Student and Result

Problem Statement

Write a C++ program to create a base class Student containing roll number and name. Derive a class Result containing marks. Accept and display the complete student result using single inheritance.

Theory / Concept

Result is the derived class and Student is the base class. Result reuses the accessible student details and adds marks.

SYNTAX

Single Inheritance

class Student
{
};

class Result : public Student
{
};

Algorithm

  1. Define the Student base class.
  2. Declare roll number and name.
  3. Define the Result derived class.
  4. Add marks to the Result class.
  5. Accept student details and marks.
  6. Display all details.
  7. Stop the program.

C++ Program

#include <iostream>
#include <string>

using namespace std;

class Student
{
protected:
    int rollNo;
    string name;

public:
    void acceptStudent()
    {
        cout << "Enter Roll No: ";
        cin >> rollNo;

        cout << "Enter Name: ";
        cin >> name;
    }
};

class Result : public Student
{
    float marks;

public:
    void acceptResult()
    {
        acceptStudent();

        cout << "Enter Marks: ";
        cin >> marks;
    }

    void display()
    {
        cout << "\nRoll No: " << rollNo << endl;
        cout << "Name: " << name << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main()
{
    Result r;

    r.acceptResult();
    r.display();

    return 0;
}

Expected Output

Enter Roll No: 101
Enter Name: Rahul
Enter Marks: 85.5

Roll No: 101
Name: Rahul
Marks: 85.5
VISUAL EXPLANATION

Student → Result

StudentrollNo, name
↓
Resultinherits Student + marks

Program Explanation

  • Student is the base class.
  • Result is derived from Student using public inheritance.
  • Result can use the protected members rollNo and name.
  • Result adds its own marks data member.

Real-Life Connection

A result record is a specialized form of student information, so common student details can be reused instead of being declared again.

Key Points

  • One base class is inherited by one derived class.
  • Inheritance promotes code reusability.
  • The derived class can add new members.

Common Errors

Wrong Syntax

Use a colon followed by the inheritance access specifier and base class.

Private Access

Private base-class members cannot be accessed directly in the derived class.

Wrong Class

Make sure the intended base and derived class relationship is defined.

Missing Object

Create an object of the derived class to use inherited functionality.

TYPE 02

Multilevel Inheritance

In multilevel inheritance, a class is derived from another derived class, forming a chain of inheritance.

PROBLEM 02.1

Student → Marks → Result

Problem Statement

Write a C++ program to create three classes Student, Marks, and Result. Derive Marks from Student and Result from Marks. Accept student details and marks and display the final result using multilevel inheritance.

Theory / Concept

Multilevel inheritance forms a chain. Result inherits from Marks, and Marks inherits from Student, so Result can use the accessible members provided through both levels.

SYNTAX

Multilevel Inheritance

class A
{
};

class B : public A
{
};

class C : public B
{
};

Algorithm

  1. Create Student as the first base class.
  2. Create Marks derived from Student.
  3. Create Result derived from Marks.
  4. Accept roll number, name and marks.
  5. Calculate total and percentage.
  6. Display the result.

C++ Program

#include <iostream>
#include <string>

using namespace std;

class Student
{
protected:
    int rollNo;
    string name;

public:
    void acceptStudent()
    {
        cout << "Enter Roll No: ";
        cin >> rollNo;

        cout << "Enter Name: ";
        cin >> name;
    }
};

class Marks : public Student
{
protected:
    float m1, m2, m3;

public:
    void acceptMarks()
    {
        acceptStudent();

        cout << "Enter 3 Marks: ";
        cin >> m1 >> m2 >> m3;
    }
};

class Result : public Marks
{
public:
    void display()
    {
        float total = m1 + m2 + m3;
        float percentage = total / 3;

        cout << "\nRoll No: " << rollNo << endl;
        cout << "Name: " << name << endl;
        cout << "Total: " << total << endl;
        cout << "Percentage: " << percentage << "%" << endl;
    }
};

int main()
{
    Result r;

    r.acceptMarks();
    r.display();

    return 0;
}

Expected Output

Enter Roll No: 101
Enter Name: Rahul
Enter 3 Marks: 80 90 85

Roll No: 101
Name: Rahul
Total: 255
Percentage: 85%
VISUAL EXPLANATION

Three-Level Inheritance Chain

StudentrollNo, name
↓
Marksm1, m2, m3
↓
Resulttotal, percentage

Program Explanation

  • Marks inherits Student.
  • Result inherits Marks.
  • Result therefore receives the accessible members from the inheritance chain.
  • The final class performs the result calculation.

Real-Life Connection

An academic system can progressively extend a basic student record into marks and then final result information.

Key Points

  • Inheritance occurs in levels.
  • Each derived class can add new features.
  • The final derived class can access inherited accessible members.

Common Errors

Wrong Chain

Result should inherit from Marks, not directly from Student.

Access

Use protected members when they need to be accessed by further derived classes.

Calculation

Use the correct total and percentage calculation.

Class Order

Define the base class before the class that inherits it.

PROBLEM 03.1

Academic + Sports → Student Result

Problem Statement

Write a C++ program to create two base classes Academic and Sports. Create a derived class StudentResult that inherits from both classes. Accept academic marks and sports score and display the combined result using multiple inheritance.

Theory / Concept

StudentResult combines information supplied by two independent base classes. This demonstrates multiple inheritance.

SYNTAX

Multiple Inheritance

class Base1
{
};

class Base2
{
};

class Derived : public Base1, public Base2
{
};

Algorithm

  1. Create Academic and Sports base classes.
  2. Declare marks in Academic and sports score in Sports.
  3. Create StudentResult derived from both.
  4. Accept both scores.
  5. Calculate combined score.
  6. Display the result.

C++ Program

#include <iostream>

using namespace std;

class Academic
{
protected:
    float academicMarks;

public:
    void acceptAcademic()
    {
        cout << "Enter Academic Marks: ";
        cin >> academicMarks;
    }
};

class Sports
{
protected:
    float sportsScore;

public:
    void acceptSports()
    {
        cout << "Enter Sports Score: ";
        cin >> sportsScore;
    }
};

class StudentResult : public Academic, public Sports
{
public:
    void display()
    {
        cout << "\nAcademic Marks: " << academicMarks << endl;
        cout << "Sports Score: " << sportsScore << endl;
        cout << "Combined Score: "
             << academicMarks + sportsScore << endl;
    }
};

int main()
{
    StudentResult s;

    s.acceptAcademic();
    s.acceptSports();
    s.display();

    return 0;
}

  • One derived class has multiple base classes.

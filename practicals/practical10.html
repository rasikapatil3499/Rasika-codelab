CONCEPT

Understanding Constructors

What is a Constructor?

A constructor is a special member function of a class that is automatically called when an object is created.

Its main purpose is to initialize the data members of an object.

A constructor has the same name as the class and does not have a return type. 

class Student
{
public:

    Student()
    {
        // initialization
    }
};

Real-Life Example

Think about creating a new student record in a college system. When the record is created, basic information such as roll number or name can be initialized immediately.

A constructor performs a similar job in an object-oriented program. It prepares the object for use as soon as it is created.

Where & How Is It Used?

  • Student Systems: Initialize student records.
  • Banking Systems: Initialize account details.
  • Employee Systems: Initialize employee information.
  • Game Development: Initialize player or game objects.
  • Inventory Systems: Initialize product objects.
TYPES

Types of Constructors

Each constructor type is explained with its own syntax in the corresponding problem below.

TYPE 01

Default Constructor

Does not take parameters and initializes an object with default values.

TYPE 02

Parameterized Constructor

Accepts parameters and initializes an object with specific values.

TYPE 03

Copy Constructor

Creates a new object by copying the state of an existing object.

TYPE 04

Multiple Constructors

Uses different constructors with different parameter lists. This is constructor overloading.

PROBLEM 01

Default Constructor

Problem Statement

Write a C++ program to create a class Student with roll number and name as data members. Use a default constructor to initialize the student details and display them.

Theory / Concept

A default constructor does not take any arguments. It is automatically called when an object is created without passing values.

SYNTAX

Default Constructor Syntax

class ClassName
{
public:
    ClassName()
    {
        // initialization
    }
};

Object Creation:

ClassName obj;

Algorithm

  1. Start the program.
  2. Define the Student class.
  3. Declare roll number and name.
  4. Define a default constructor.
  5. Initialize the data members inside the constructor.
  6. Create a Student object.
  7. Display the initialized details.
  8. Stop the program.

C++ Program

#include <iostream>
#include <string>

using namespace std;

class Student
{
    int rollNo;
    string name;

public:

    Student()
    {
        rollNo = 101;
        name = "Rahul";
    }

    void display()
    {
        cout << "Roll No: " << rollNo << endl;
        cout << "Name: " << name << endl;
    }
};

int main()
{
    Student s;

    s.display();

    return 0;
}

Expected Output

Roll No: 101
Name: Rahul
VISUAL EXPLANATION

Default Constructor Flow

Student s Object created
→
Student() Constructor called
→
rollNo = 101 name = Rahul

Program Explanation

  • The constructor has the same name as the class.
  • It does not have a return type.
  • It is called automatically when object s is created.
  • The constructor initializes roll number and name.

Real-Life Connection

A default constructor can assign standard or default values when a new record is created.

Key Points

  • No parameters are passed.
  • Called automatically during object creation.
  • Useful for assigning default values.

Common Errors

Return Type

A constructor must not have a return type.

Wrong Name

Constructor name must match the class name.

Parameters

A default constructor has no parameters.

Object Creation

Create the object correctly to invoke the constructor.

PROBLEM 02

Parameterized Constructor

Problem Statement

Write a C++ program to create a class Rectangle containing length and breadth. Use a parameterized constructor to initialize the values and calculate the area of the rectangle.

Theory / Concept

A parameterized constructor accepts one or more arguments. These arguments are used to initialize the object's data members with values supplied during object creation.

Formula

Area

Area = Length × Breadth

SYNTAX

Parameterized Constructor Syntax

class ClassName
{
public:
    ClassName(data_type value1, data_type value2)
    {
        // initialization
    }
};

Object Creation:

ClassName obj(value1, value2);

Algorithm

  1. Start the program.
  2. Define the Rectangle class.
  3. Declare length and breadth.
  4. Define a parameterized constructor.
  5. Pass length and breadth while creating the object.
  6. Calculate the area.
  7. Display the area.
  8. Stop the program.

C++ Program

#include <iostream>

using namespace std;

class Rectangle
{
    int length;
    int breadth;

public:

    Rectangle(int l, int b)
    {
        length = l;
        breadth = b;
    }

    void displayArea()
    {
        cout << "Length: " << length << endl;
        cout << "Breadth: " << breadth << endl;
        cout << "Area: " << length * breadth << endl;
    }
};

int main()
{
    Rectangle r(10, 5);

    r.displayArea();

    return 0;
}

Expected Output

Length: 10
Breadth: 5
Area: 50
VISUAL EXPLANATION

Parameterized Constructor Flow

Rectangle r Object
→
r(10, 5) Arguments
→
length = 10 breadth = 5
→
Area = 50 Result

Program Explanation

  • The constructor receives l and b.
  • These values are assigned to length and breadth.
  • Rectangle r(10, 5) invokes the constructor automatically.
  • The area is calculated using length × breadth.

Real-Life Connection

A drawing or building application can create rectangle objects with different dimensions. A parameterized constructor allows each object to receive its own dimensions during creation.

Key Points

  • Parameters are passed during object creation.
  • Different objects can receive different values.
  • Useful when objects require specific initial values.

Common Errors

Wrong Arguments

Pass the correct number and type of arguments.

Constructor Name

The constructor name must match the class name.

Missing Constructor

Define the parameterized constructor before using it.

Calculation

Use the correct formula for area.

PROBLEM 03

Copy Constructor

Problem Statement

Write a C++ program to create a class Student with roll number and marks. Use a copy constructor to create a second object from the first object and display the details of both objects.

Theory / Concept

A copy constructor initializes a new object using an existing object of the same class. 

ClassName(const ClassName &obj)
{
    // copy data
}
SYNTAX

Copy Constructor Syntax

class ClassName
{
public:
    ClassName(const ClassName &obj)
    {
        // copy data members
    }
};

Object Creation:

ClassName obj1;
ClassName obj2(obj1);

Algorithm

  1. Start the program.
  2. Define the Student class.
  3. Declare roll number and marks.
  4. Create a parameterized constructor to initialize the first object.
  5. Define a copy constructor.
  6. Create the second object using the first object.
  7. Display both objects.
  8. Stop the program.

C++ Program

#include <iostream>

using namespace std;

class Student
{
    int rollNo;
    float marks;

public:

    Student(int r, float m)
    {
        rollNo = r;
        marks = m;
    }

    Student(const Student &s)
    {
        rollNo = s.rollNo;
        marks = s.marks;
    }

    void display()
    {
        cout << "Roll No: " << rollNo << endl;
        cout << "Marks: " << marks << endl;
    }
};

int main()
{
    Student s1(101, 85.5);

    Student s2(s1);

    cout << "First Object\n";
    s1.display();

    cout << "\nCopied Object\n";
    s2.display();

    return 0;
}

Expected Output

First Object
Roll No: 101
Marks: 85.5

Copied Object
Roll No: 101
Marks: 85.5
VISUAL EXPLANATION

Copy Constructor Flow

s1 Roll: 101
Marks: 85.5
→
Copy Constructor Student s2(s1)
→
s2 Roll: 101
Marks: 85.5

Program Explanation

  • s1 is created using the parameterized constructor.
  • Student s2(s1) creates a new object using s1.
  • The copy constructor copies the data members from s1 into s2.
  • Both objects contain the same initial values.

Real-Life Connection

A copy constructor can be useful when creating a duplicate record based on an existing record, such as creating a copy of a student or product object.

Key Points

  • It receives an object of the same class.
  • It initializes a new object.
  • It is useful for copying object state.

Common Errors

Wrong Parameter

A copy constructor should receive an object of the same class, conventionally by reference.

Wrong Class Name

The constructor name must match the class name.

Wrong Object

Pass the existing object when creating the copied object.

Missing Data Copy

Copy all required data members.

PROBLEM 04

Multiple Constructors in One Class

Problem Statement

Write a C++ program to create a class Rectangle having multiple constructors: a default constructor, a parameterized constructor for a square, and another parameterized constructor for a rectangle. Display the area calculated by each object.

Theory / Concept

A class can contain more than one constructor as long as their parameter lists are different. This is an example of constructor overloading.

SYNTAX

Multiple Constructors Syntax

class ClassName
{
public:
    ClassName()
    {
        // default initialization
    }

    ClassName(data_type value)
    {
        // initialization
    }

    ClassName(data_type value1, data_type value2)
    {
        // initialization
    }
};

Object Creation:

ClassName obj1;
ClassName obj2(value);
ClassName obj3(value1, value2);

Algorithm

  1. Start the program.
  2. Define the Rectangle class.
  3. Define a default constructor.
  4. Define a constructor with one parameter for a square.
  5. Define a constructor with two parameters for a rectangle.
  6. Create objects using different constructors.
  7. Calculate and display the areas.
  8. Stop the program.

C++ Program

#include <iostream>

using namespace std;

class Rectangle
{
    int length;
    int breadth;

public:

    // Default constructor
    Rectangle()
    {
        length = 1;
        breadth = 1;
    }

    // Constructor for square
    Rectangle(int side)
    {
        length = side;
        breadth = side;
    }

    // Constructor for rectangle
    Rectangle(int l, int b)
    {
        length = l;
        breadth = b;
    }

    void displayArea()
    {
        cout << "Length: " << length << endl;
        cout << "Breadth: " << breadth << endl;
        cout << "Area: " << length * breadth << endl;
        cout << endl;
    }
};

int main()
{
    Rectangle r1;

    Rectangle r2(5);

    Rectangle r3(10, 4);

    cout << "Object 1\n";
    r1.displayArea();

    cout << "Object 2\n";
    r2.displayArea();

    cout << "Object 3\n";
    r3.displayArea();

    return 0;
}

Expected Output

Object 1
Length: 1
Breadth: 1
Area: 1

Object 2
Length: 5
Breadth: 5
Area: 25

Object 3
Length: 10
Breadth: 4
Area: 40
VISUAL EXPLANATION

Constructor Overloading

01
r1 Rectangle()
1 × 1
02
r2 Rectangle(5)
5 × 5
03
r3 Rectangle(10,4)
10 × 4

Program Explanation

  • The class contains three constructors.
  • Each constructor has a different parameter list.
  • Rectangle r1 calls the default constructor.
  • Rectangle r2(5) calls the one-parameter constructor.
  • Rectangle r3(10,4) calls the two-parameter constructor.

Real-Life Connection

Different ways of creating an object are common in software systems. For example, a product may be created with default information, only a price, or complete product details.

Key Points

  • Multiple constructors can exist in one class.
  • Constructors must have different parameter lists.
  • This concept is called constructor overloading.
  • The compiler selects the appropriate constructor based on the arguments.

Common Errors

Same Parameter List

Two constructors cannot have exactly the same parameter list.

Wrong Arguments

Pass arguments matching the intended constructor.

Constructor Name

Every constructor must have the same name as the class.

Return Type

Constructors do not have a return type.

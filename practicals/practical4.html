03 — EXPLORE THE CONCEPT

Classes, Objects & Member Functions

Understand how a class acts as a blueprint and how objects use the data and functions defined inside it.

Theory

A class is a user-defined data type that groups data members and member functions together. It provides a blueprint for creating objects.

An object is an instance of a class. Each object can access the data members and member functions defined within the class.

In this practical, the member functions are defined inside the class. This means the function definition is written within the class body itself.

Class → Object → Function Call
🌍

Real-Life Example

Consider a Student in a college system. A student has properties such as name, roll number and marks. A class can represent the common structure of a student, while individual students can be represented using objects.

Where & How Is It Used?

Student Management

A Student class can store student information and functions can display or calculate student details.

Banking Systems

An Account class can contain account data and functions such as deposit and withdrawal.

Billing Systems

A Product class can contain product information and functions to calculate prices or totals.

PROBLEM 01

Student Details

Problem Statement

Write a C++ program to create a class Student with data members roll number and name. Define a function inside the class to accept and display student details. Create an object of the class and call the function.

Algorithm

  1. Start.
  2. Define a class named Student.
  3. Declare roll number and name as data members.
  4. Define a function inside the class to accept student details.
  5. Define another function inside the class to display the details.
  6. Create an object of Student.
  7. Call the member functions using the object.
  8. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Student
{
    int rollNo;
    string name;

public:

    void accept()
    {
        cout << "Enter roll number: ";
        cin >> rollNo;

        cout << "Enter name: ";
        cin >> name;
    }

    void display()
    {
        cout << "\nRoll Number = "
             << rollNo << endl;

        cout << "Name = "
             << name;
    }
};

int main()
{
    Student s;

    s.accept();
    s.display();

    return 0;
}

Expected Output 

Enter roll number: 101
Enter name: Rahul

Roll Number = 101
Name = Rahul
CLASS & OBJECT VISUALIZATION

Class → Object → Function

The class defines the structure, the object represents an instance, and the object calls the functions.

CLASS Student rollNo name
→
OBJECT s rollNo = 101 name = Rahul
→

Program Explanation

  • Student is the class containing student data and functions.
  • s is an object of the Student class.
  • accept() accepts the student's details.
  • display() displays the stored details.
  • Both functions are defined directly inside the class.

Key Points

  • A class is a blueprint for objects.
  • An object is an instance of a class.
  • Member functions can be defined inside the class.
  • Functions are accessed using the object and dot operator.

Common Errors

Missing Object

A member function is generally called through an object when working with ordinary class objects.

Wrong Function Call

Use the correct syntax such as s.display().

PROBLEM 02

Rectangle Area and Perimeter

Problem Statement

Write a C++ program to create a class Rectangle with data members length and breadth. Define functions inside the class to calculate and display the area and perimeter of the rectangle.

Formula

Area length × breadth
Perimeter 2 × (length + breadth)

Algorithm

  1. Start.
  2. Define a class Rectangle.
  3. Declare length and breadth.
  4. Define a function to accept dimensions.
  5. Define a function to calculate area and perimeter.
  6. Create an object of Rectangle.
  7. Call the required functions.
  8. Display the results.
  9. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Rectangle
{
    float length;
    float breadth;

public:

    void accept()
    {
        cout << "Enter length: ";
        cin >> length;

        cout << "Enter breadth: ";
        cin >> breadth;
    }

    void calculate()
    {
        float area = length * breadth;

        float perimeter =
            2 * (length + breadth);

        cout << "\nArea = "
             << area << endl;

        cout << "Perimeter = "
             << perimeter;
    }
};

int main()
{
    Rectangle r;

    r.accept();
    r.calculate();

    return 0;
}

Expected Output 

Enter length: 10
Enter breadth: 5

Area = 50
Perimeter = 30
OBJECT VISUALIZATION

Rectangle Object

The object stores the dimensions and its member function performs the calculations.

10 5
r length = 10 breadth = 5 area = 50

Program Explanation

  • Rectangle is the class.
  • r is the object.
  • accept() receives the rectangle dimensions.
  • calculate() calculates area and perimeter.
  • The functions are defined inside the class.

Real-Life Connection

Similar class-based logic can be used in architectural and engineering software to represent shapes and calculate their dimensions.

Key Points

  • Data and operations related to a rectangle are grouped inside one class.
  • Member functions operate on the object's data.

Common Errors

Incorrect Formula

Check the area and perimeter formulas carefully.

Wrong Object Name

Use the same object name when calling member functions.

PROBLEM 03

Employee Salary

Problem Statement

Write a C++ program to create a class Employee with data members employee ID, name and basic salary. Define functions inside the class to accept employee details and calculate the gross salary.

Concept

A class can combine employee information with the functions that operate on that information. The object represents one employee record.

Algorithm

  1. Start.
  2. Define an Employee class.
  3. Declare employee ID, name and basic salary.
  4. Define a function to accept details.
  5. Define a function to calculate gross salary.
  6. Create an Employee object.
  7. Call the member functions.
  8. Display employee information and gross salary.
  9. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Employee
{
    int empId;
    string name;
    float basicSalary;

public:

    void accept()
    {
        cout << "Enter employee ID: ";
        cin >> empId;

        cout << "Enter name: ";
        cin >> name;

        cout << "Enter basic salary: ";
        cin >> basicSalary;
    }

    void display()
    {
        float hra = basicSalary * 0.20;
        float da = basicSalary * 0.10;

        float grossSalary =
            basicSalary + hra + da;

        cout << "\nEmployee ID = "
             << empId << endl;

        cout << "Name = "
             << name << endl;

        cout << "Basic Salary = "
             << basicSalary << endl;

        cout << "Gross Salary = "
             << grossSalary;
    }
};

int main()
{
    Employee e;

    e.accept();
    e.display();

    return 0;
}

Expected Output 

Enter employee ID: 101
Enter name: Amit
Enter basic salary: 30000

Employee ID = 101
Name = Amit
Basic Salary = 30000
Gross Salary = 39000
CLASS VISUALIZATION

Employee Object

OBJECT e
ID → 101 Name → Amit Salary → ₹30,000
→
MEMBER FUNCTION display() Calculates gross salary

Program Explanation

  • Employee is the class containing employee data.
  • e is an object of the Employee class.
  • accept() accepts employee information.
  • display() calculates and displays the gross salary.
  • Both member functions are defined inside the class.

Real-Life Connection

Employee classes are commonly used in payroll systems to store employee details and perform salary-related calculations.

Key Points

  • Classes combine related data and functions.
  • Different objects can represent different employees.
  • Functions defined inside the class can directly work with its data members.

Common Errors

Incorrect Salary Calculation

Verify the HRA, DA and gross salary calculation.

Accessing Private Data

Private data members should be accessed through member functions.

Test Your Understanding

Classes & Objects

What is a class?

A class is a user-defined data type that groups data members and member functions together.

What is an object?

An object is an instance of a class.

What is a member function?

A member function is a function that belongs to a class and operates on its data members.

How do you create an object?

An object can be created using the class name followed by the object name, for example Student s;.

Functions Inside Class

Where is the function defined in this practical?

The member function is defined directly inside the class body.

How is a member function called?

A member function can be called using an object and the dot operator, such as s.display().

Why are classes useful?

Classes allow related data and functions to be grouped together, making programs easier to organize and maintain.

Can multiple objects be created from one class?

Yes. Multiple objects can be created from the same class, and each object can represent a separate instance.

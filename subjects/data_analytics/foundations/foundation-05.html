Good Analysis vs Poor Analysis

âœ“ Good Analysis

  • Starts with a clear question.
  • Uses appropriate data.
  • Chooses the correct visualization.
  • Explains the important pattern.
  • Provides evidence for conclusions.
  • Ends with a useful recommendation.

âœ• Poor Analysis

  • Creates charts without a purpose.

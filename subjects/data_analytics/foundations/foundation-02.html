Before Analysis, Understand the Data

Before creating a chart, calculating an average, or building a dashboard, an analyst must understand where the data came from and how it is organized. Data source and structure influence what questions can be answered reliably.

Where does data come from?

Data can be collected from many different sources such as databases, spreadsheets, websites, applications, sensors, APIs, surveys, business systems and public datasets.

Why does structure matter?

A well-structured dataset makes it easier to filter, calculate, compare, visualize and communicate information. Poor structure can produce incorrect or misleading analysis.

06 Â· Data Identification

Why Does a Primary Key Matter?

A unique identifier helps distinguish one record from another. This becomes particularly important when working with databases and combining datasets.

Example: Student_ID

If every student has a unique Student_ID, the analyst can identify individual records reliably.

UNIQUE Each record should have a distinct identifier.
IDENTIFIABLE The record can be located and referenced clearly.
USEFUL FOR COMBINING Identifiers can help connect related datasets.
07 Â· Data Formats

CSV vs JSON vs Database

Data can be represented in different formats. The appropriate format depends on the application, structure and workflow.

CSV

Student_ID,Marks ST001,86 ST002,58 ST003,88

Simple tabular representation suitable for spreadsheets and many analytical tools.

JSON

{ "student": "ST001", "marks": 86 }

Frequently used for exchanging structured information between applications and APIs.

Database

STUDENT ---------------- ID NAME MARKS

Suitable for structured information that needs persistent storage and querying.

04 — MISSING VALUES

What Should You Do With Missing Data?

There is no single solution. The correct approach depends on the dataset and the reason the value is missing.

01

Remove

Remove records when missing information makes the record unusable and the loss is acceptable.

dropna()
02

Fill

Replace missing numerical values using appropriate statistics such as mean or median.

fillna()
03

Use a Category

For categorical fields, a meaningful category such as "Unknown" may be appropriate.

"Unknown"
04

Investigate

Sometimes missing data itself provides useful information about the process.

Analyze the cause
05 — OUTLIERS

Not Every Unusual Value Is Wrong

An outlier may represent an error, or it may represent a genuinely unusual event.

48 50 51 52 53 490
Normal observations
490 Investigate
Should 490 be deleted?

Not automatically. It could be a typing error, a genuine extreme event, or a different population. Always investigate first.

REAL-WORLD THINKING

Cleaning is About Decisions

The analyst should never modify data blindly. Every cleaning decision should have a reason.

Problem Missing salary → Investigate why it is missing
Problem Duplicate customer → Determine whether it is truly duplicate
Problem Age = 250 → Validate before changing
Problem Mumbai / MUM / mumbai → Standardize categories
KEY TAKEAWAYS

Remember These Rules

01

Never assume raw data is clean.

02

Missing data needs investigation, not automatic deletion.

03

Duplicate and inconsistent records can distort analysis.

04

Outliers should be investigated before being removed.

05

Clean data produces more reliable analysis and visualizations.

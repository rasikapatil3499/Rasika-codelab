PRACTICAL 04

Turn Data Into Visual Stories

Numbers alone do not communicate insights effectively. In this practical, you will select appropriate charts, build visualizations, design dashboards, add filters, and communicate analytical findings through visual storytelling.

Data Visualization Chart Selection Bar Chart Line Chart Scatter Plot Histogram Dashboard Data Storytelling
01 — VISUALIZATION MINDSET

Choose the visual for the question

A good visualization is not decoration. It should make a relationship, comparison, trend or distribution easier to understand.

01 — COMPARE

Which is higher?

Use visualizations to compare products, departments, categories, cities or groups.

02 — TREND

How is it changing?

Show increases, decreases, seasonality and changes across time.

03 — DISTRIBUTION

How is data spread?

Understand frequency, range, skewness, clusters and unusual observations.

04 — RELATIONSHIP

Are variables related?

Visualize relationships between numerical variables using scatter plots and similar techniques.

02 — CHART SELECTION

The right chart for the right question

Students should learn to select a chart based on the analytical purpose rather than using the same chart for every dataset.

▮

Bar Chart

Compare values across discrete categories.

Use for: Product sales, departments, cities
╱

Line Chart

Show trends and changes across continuous time.

Use for: Monthly sales, temperature, traffic
•

Scatter Plot

Examine relationships between two numerical variables.

Use for: Study hours vs marks
▥

Histogram

Understand the distribution of a numerical variable.

Use for: Age, salary, marks
%

Pie / Donut Chart

Show simple part-to-whole relationships when categories are limited.

Use for: Market share, category share
▤

Heatmap

Display intensity or relationships across a matrix.

Use for: Correlation matrix, attendance
03 — DECISION GUIDE

Question → Visualization

Question Data Type Recommended Chart Example
Which category is largest? Categorical + Numerical Bar Chart Product Sales
How did it change over time? Date + Numerical Line Chart Monthly Revenue
How is the data distributed? Numerical Histogram Employee Salary
Are two variables related? Numerical + Numerical Scatter Plot Hours vs Marks
What percentage does each category contribute? Categorical + Numerical Donut Chart Market Share
Where are values concentrated? Matrix / Numerical Heatmap Correlation

06 — REAL-WORLD PROBLEMS

Build visualizations for real decisions

Complete all three problems. Each problem should contain multiple visualizations and a short written interpretation.

PROBLEM 01

E-Commerce Dashboard

Management wants a dashboard to understand product performance and monthly revenue.

Visualizations
  • Monthly revenue → Line Chart
  • Product sales → Bar Chart
  • Category contribution → Donut Chart
  • Order value distribution → Histogram
Dashboard KPIs
  • Total Revenue
  • Total Orders
  • Average Order Value
  • Top Product
Answer
  • Which product performs best?
  • Which month generated highest revenue?
  • What percentage of sales comes from the top category?
Add at least one filter.
PROBLEM 02

Student Performance Dashboard

A college wants to identify academic performance patterns across divisions and attendance levels.

Visualizations
  • Average marks by subject → Bar Chart
  • Attendance vs marks → Scatter Plot
  • Marks distribution → Histogram
  • Division performance → Bar Chart
Dashboard KPIs
  • Average Marks
  • Pass Percentage
  • Average Attendance
  • Highest Score
Answer
  • Which division performs best?
  • Is attendance associated with marks?
  • Which subject needs attention?
Include a correlation visualization.
PROBLEM 03

Employee Analytics Dashboard

HR wants to understand employee performance, salary distribution and departmental differences.

Visualizations
  • Salary by department → Bar Chart
  • Experience vs salary → Scatter Plot
  • Salary distribution → Histogram
  • Employee count → Donut Chart
Dashboard KPIs
  • Total Employees
  • Average Salary
  • Average Experience
  • Average Performance
Answer
  • Which department has the highest salary?
  • Does experience relate to salary?
  • Where are performance gaps visible?
Explain at least three insights.
07 — DATA STORYTELLING

From chart to decision

A dashboard becomes useful when the analyst can explain what happened, why it matters and what should happen next.

01

What?

Describe the important observation visible in the data or visualization.

02

So What?

Explain why the observation is important to the business, organization or user.

03

Why?

Investigate possible factors or relationships that could explain the observation.

04

Now What?

Suggest a practical action, recommendation or next analytical step.

08 — VISUAL DESIGN RULES

Make your dashboard easy to read

Give every chart a meaningful title.
Do not use a chart when a simple number is enough.
Avoid unnecessary 3D effects.
Keep colours consistent across the dashboard.
Highlight important values rather than everything.
Use labels and units clearly.
Avoid overcrowding the dashboard.
Every visual should support a question or decision.
Use filters only when they provide analytical value.
Always write the important insights below the visuals.

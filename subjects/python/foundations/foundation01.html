What is Python?

Python is a high-level, general-purpose programming language designed to make programs readable and expressive.

Why Python?

  • Simple and readable syntax
  • Large standard library
  • Strong ecosystem of packages
  • Used in web, data, automation and AI

Problem: Student Result

Write a Python program that accepts marks for three subjects, calculates the average, and determines whether the student has passed.

Concepts Used

Variables Input Numbers Operators Conditions

Example

math = 80
science = 72
python = 88

average = (math + science + python) / 3

if average >= 40:
    print("Pass")
else:
    print("Fail")
Think Further

How would you modify the program to calculate a grade such as A, B, C or F?

Python Code

expense_tracker.py 

expenses = []


def add_expense(
    date,
    category,
    description,
    amount
):

    expense = {

        "date": date,
        "category": category,
        "description": description,
        "amount": amount

    }

    expenses.append(expense)


def calculate_total():

    return sum(
        expense["amount"]
        for expense in expenses
    )


def category_total(category):

    return sum(
        expense["amount"]
        for expense in expenses
        if expense["category"] == category
    )


def display_expenses():

    print("\n--- Expense Report ---")

    for expense in expenses:

        print(
            expense["date"],
            "|",
            expense["category"],
            "|",
            expense["description"],
            "| ₹",
            expense["amount"]
        )


add_expense(
    "20-09-2026",
    "Food",
    "Lunch",
    180
)

add_expense(
    "20-09-2026",
    "Travel",
    "Bus",
    40
)

add_expense(
    "21-09-2026",
    "Education",
    "Book",
    450
)


display_expenses()

print(
    "\nTotal Spending: ₹",
    calculate_total()
)

print(
    "Food Spending: ₹",
    category_total("Food")
)

Problem 02 — Student Performance Dashboard

Problem Description

Develop a Python application that processes student marks and generates meaningful academic performance information.

Required Analysis

Metric Description
Average Average marks of all students.
Highest Highest scoring student.
Lowest Lowest scoring student.
Pass Percentage Percentage of students who passed.
Grade Distribution Number of students in each grade.

Example Code

performance.py 

students = [

    {
        "name": "Aarav",
        "marks": 82
    },

    {
        "name": "Priya",
        "marks": 91
    },

    {
        "name": "Rahul",
        "marks": 68
    },

    {
        "name": "Sneha",
        "marks": 76
    },

    {
        "name": "Amit",
        "marks": 54
    }

]


def average_marks(data):

    total = sum(
        student["marks"]
        for student in data
    )

    return total / len(data)


def highest_scorer(data):

    return max(
        data,
        key=lambda student:
        student["marks"]
    )


def lowest_scorer(data):

    return min(
        data,
        key=lambda student:
        student["marks"]
    )


def pass_percentage(data):

    passed = sum(
        1
        for student in data
        if student["marks"] >= 40
    )

    return (
        passed / len(data)
    ) * 100


print(
    "Average:",
    average_marks(students)
)

print(
    "Highest:",
    highest_scorer(students)
)

print(
    "Lowest:",
    lowest_scorer(students)
)

print(
    "Pass Percentage:",
    pass_percentage(students)
)

Viva Questions

1. Why should a large program be divided into functions?
Functions divide a program into smaller reusable units, making the application easier to understand, test and maintain.
2. Why are classes useful in a real-world application?
Classes allow related data and behavior to be organized into reusable objects.
3. Why is persistent storage required?
Persistent storage allows application data to remain available after the program terminates.
4. What is CRUD?
CRUD represents Create, Read, Update and Delete operations.
5. What is exception handling?
Exception handling provides a structured way to detect and handle runtime errors.
6. What makes an application modular?
Separating an application into logical functions, classes and components makes it more modular and maintainable.
7. How can a Python application be extended in the future?
New functions, classes, database tables, interfaces or external services can be added without rewriting the entire application.

Python Code

student_data.py 

students = [

    {
        "name": "Aarav",
        "marks": 82,
        "department": "Computer"
    },

    {
        "name": "Priya",
        "marks": 91,
        "department": "Computer"
    },

    {
        "name": "Rahul",
        "marks": 68,
        "department": "IT"
    },

    {
        "name": "Sneha",
        "marks": 76,
        "department": "Computer"
    }

]


def display_students(data):

    for student in data:

        print(
            student["name"],
            "-",
            student["marks"],
            "-",
            student["department"]
        )


def calculate_average(data):

    total = sum(
        student["marks"]
        for student in data
    )

    return total / len(data)


def highest_scorer(data):

    return max(
        data,
        key=lambda student: student["marks"]
    )


def filter_students(data, minimum_marks):

    return [
        student
        for student in data
        if student["marks"] >= minimum_marks
    ]


print("STUDENT RECORDS")
print("----------------")

display_students(students)


average = calculate_average(students)

print("\nAverage Marks:", average)


topper = highest_scorer(students)

print(
    "Highest Scorer:",
    topper["name"],
    topper["marks"]
)


print("\nStudents scoring 75 or above:")

filtered = filter_students(
    students,
    75
)

display_students(filtered)

Problem 03 â€” Filter & Transform

Problem Description

Given a collection of student records, use Python functions and data transformation techniques to filter students and generate a new collection containing only the required information.

Example

transform.py 

students = [
    {"name": "Aarav", "marks": 82},
    {"name": "Priya", "marks": 91},
    {"name": "Rahul", "marks": 68},
    {"name": "Sneha", "marks": 76}
]

result = list(
    filter(
        lambda student:
        student["marks"] >= 75,
        students
    )
)

names = list(
    map(
        lambda student:
        student["name"],
        result
    )
)

print(names)

Expected Output 

['Aarav', 'Priya', 'Sneha']

Viva Questions

1. What is a function in Python?
A function is a reusable block of code designed to perform a specific task.
2. What is the difference between a parameter and an argument?
A parameter is a variable defined in the function definition, while an argument is the actual value passed to the function.
3. What is the purpose of return?
The return statement sends a value from a function back to the calling code.
4. What is a dictionary?
A dictionary stores data as key-value pairs.
5. What does lambda mean in Python?
A lambda is a small anonymous function that can contain a single expression.
6. What is the purpose of filter()?
The filter() function selects elements from an iterable based on a condition.
7. What does map() do?
The map() function applies a function to each item of an iterable.

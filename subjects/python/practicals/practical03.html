Python Code

student.py 

class Student:

    def __init__(
        self,
        student_id,
        name,
        department,
        marks
    ):

        self.student_id = student_id
        self.name = name
        self.department = department
        self.marks = marks


    def display(self):

        print("\n--- Student Details ---")

        print("ID         :", self.student_id)
        print("Name       :", self.name)
        print("Department :", self.department)
        print("Marks      :", self.marks)


    def calculate_average(self):

        return sum(self.marks) / len(self.marks)


    def get_grade(self):

        average = self.calculate_average()

        if average >= 75:
            return "Distinction"

        elif average >= 60:
            return "First Class"

        elif average >= 50:
            return "Second Class"

        elif average >= 40:
            return "Pass"

        else:
            return "Fail"


student = Student(
    "ST101",
    "Riya",
    "Computer",
    [78, 82, 75, 88, 81]
)


student.display()

print(
    "Average    :",
    student.calculate_average()
)

print(
    "Grade      :",
    student.get_grade()
)

Problem 02 — Bank Account System

Problem Description

Create a BankAccount class that allows a user to manage basic banking operations such as deposit, withdrawal and balance checking.

Required Attributes

  • Account number
  • Account holder name
  • Account balance

Required Methods

  • deposit()
  • withdraw()
  • check_balance()
  • display_account()

Example Code

bank_account.py 

class BankAccount:

    def __init__(
        self,
        account_number,
        holder_name,
        balance=0
    ):

        self.account_number = account_number
        self.holder_name = holder_name
        self.balance = balance


    def deposit(self, amount):

        if amount > 0:

            self.balance += amount

            print(
                "Amount deposited successfully."
            )


    def withdraw(self, amount):

        if amount <= self.balance:

            self.balance -= amount

            print(
                "Amount withdrawn successfully."
            )

        else:

            print(
                "Insufficient balance."
            )


    def check_balance(self):

        print(
            "Current Balance:",
            self.balance
        )


account = BankAccount(
    "ACC101",
    "Riya",
    5000
)

account.deposit(1500)

account.withdraw(2000)

account.check_balance()

Expected Output 

Amount deposited successfully.
Amount withdrawn successfully.
Current Balance: 4500

Problem 03 — Library Management

Problem Description

Design a basic library management application using multiple classes. The system should maintain books and members and support book issue and return operations.

Classes

Book Member Library

Required Operations

  • Add a new book.
  • Display available books.
  • Register a library member.
  • Issue a book to a member.
  • Return a book.

Example Structure

library.py 

class Book:

    def __init__(self, title, author):

        self.title = title
        self.author = author
        self.available = True


class Member:

    def __init__(self, member_id, name):

        self.member_id = member_id
        self.name = name


class Library:

    def __init__(self):

        self.books = []
        self.members = []


    def add_book(self, book):

        self.books.append(book)


    def register_member(self, member):

        self.members.append(member)


    def display_books(self):

        for book in self.books:

            status = (
                "Available"
                if book.available
                else "Issued"
            )

            print(
                book.title,
                "-",
                status
            )


library = Library()

book1 = Book(
    "Python Basics",
    "R. Sharma"
)

book2 = Book(
    "Data Science",
    "A. Patil"
)

member1 = Member(
    "M001",
    "Riya"
)

library.add_book(book1)
library.add_book(book2)

library.register_member(member1)

library.display_books()

Expected Output 

Python Basics - Available
Data Science - Available

Viva Questions

1. What is a class in Python?
A class is a blueprint used to create objects containing data and behavior.
2. What is an object?
An object is an instance of a class.
3. What is the purpose of __init__()?
It is commonly used as a constructor to initialize an object's attributes.
4. What is self in Python?
self refers to the current instance of a class.
5. What is encapsulation?
Encapsulation is the organization of data and related methods within a class, with controlled access to the data.
6. Can a Python class have multiple objects?
Yes. Multiple independent objects can be created from the same class.
7. Why are classes useful in application development?
Classes help organize related data and behavior into reusable structures.

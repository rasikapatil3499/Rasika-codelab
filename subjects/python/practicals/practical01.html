Sample Input & Output

Input

Marks:
78
65
91
48
84

Average     : 73.20
Highest     : 91

07

Python Code

student_marks.py 

marks = []

n = int(input("Enter number of students: "))

for i in range(n):

    mark = float(
        input(f"Enter marks for student {i + 1}: ")
    )

    marks.append(mark)


total = sum(marks)
average = total / n

highest = max(marks)
lowest = min(marks)

passed = 0

for mark in marks:

    if mark >= 40:
        passed += 1


print("\n--- Student Performance ---")

print("Total Marks :", total)
print("Average     :", average)
print("Highest     :", highest)
print("Lowest      :", lowest)
print("Passed      :", passed)

It is used to iterate over a sequence or collection.

Polygon Clipping

A polygon can extend outside the visible region. Clipping keeps only the portion inside the clipping window.

Input and Output

Input: Polygon vertices + clipping window
Output: New polygon containing only the visible region

The output can contain original vertices, boundary intersection points, or both.

Boundary-by-Boundary Processing

The rectangular window has four boundaries. The polygon is clipped against one boundary at a time.

  • LEFT: x = xmin
  • RIGHT: x = xmax
  • BOTTOM: y = ymin
  • TOP: y = ymax

Step-by-Step Pipeline

The polygon changes after every clipping pass.

1

Original Polygon

Start with the complete polygon, including vertices outside the window.

2

LEFT Pass

Remove the portion left of xmin and add boundary intersections.

3

RIGHT Pass

Use the LEFT output and clip the portion right of xmax.

4

BOTTOM + TOP

Repeat for ymin and ymax to obtain the final visible polygon.

Observe: The number of vertices is not fixed. Clipping can remove vertices and can also create new intersection vertices.

10

Common Mistakes

Wrong vertex order

Keep polygon vertices in their boundary order so consecutive vertices form polygon edges.

Missing intersection

Inside-to-outside and outside-to-inside transitions require an intersection calculation.

Using original polygon every time

The output from one clipping boundary becomes the input for the next boundary.

Wrong inside test

Use the correct inequality for the selected LEFT, RIGHT, BOTTOM or TOP boundary.

Viva Questions

Check your understanding before moving to curves.

What is polygon clipping?

It is the process of removing portions of a polygon that lie outside a specified clipping window.

What is the Sutherland-Hodgman algorithm?

It is a polygon clipping algorithm that processes a polygon against each clipping boundary sequentially.

What are the four vertex cases?

Insideâ†’Inside, Insideâ†’Outside, Outsideâ†’Inside and Outsideâ†’Outside.

What is produced for Insideâ†’Outside?

The intersection point with the clipping boundary is added.

What is produced for Outsideâ†’Inside?

The intersection point is added first, followed by the inside vertex.

Why are multiple passes required?

A rectangular clipping window has four boundaries, and the polygon is progressively clipped against each one.

Can clipping create new vertices?

Yes. Intersections between polygon edges and clipping boundaries become new output vertices.

What happens if the entire polygon is outside?

The output list can become empty after the appropriate clipping passes.

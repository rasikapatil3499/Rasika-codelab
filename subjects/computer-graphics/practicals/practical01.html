Can you explain it?

What is a pixel?

A pixel is a discrete picture element used to represent an image on a raster display.

What does resolution mean?

Resolution describes the number of pixels available horizontally and vertically, such as 1920 Ã— 1080.

What is a coordinate system?

It is a numerical system used to specify the position of points in a space.

Why is screen Y often downward?

Many raster displays use the top-left corner as the origin, so Y increases toward the bottom.

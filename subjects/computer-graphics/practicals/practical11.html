Common Mistakes

Check the transformation matrix and coordinate equation carefully.

01

Wrong Sign

For X reflection, Y changes sign. For Y reflection, X changes sign.

02

Wrong Shear Coordinate

X-shear changes X using Y. Y-shear changes Y using X.

03

Ignoring Homogeneous Coordinates

Use the 3Ã—3 homogeneous form when combining transformations with translation.

04

Confusing Reflection & Rotation

Reflection creates a mirror image; rotation changes orientation around a pivot.

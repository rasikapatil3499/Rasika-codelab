Common Mistakes

Keep these points in mind while solving transformation problems.

01

Wrong Sign

A negative translation moves the object in the opposite direction.

02

Wrong Scale

A scale factor below 1 reduces the object while a factor above 1 enlarges it.

03

Forgetting the Pivot

Scaling about the origin is different from scaling about an arbitrary fixed point.

04

Matrix Order

When multiple transformations are combined, matrix multiplication order matters.

Viva Questions

Test your understanding of translation, scaling and homogeneous coordinates.

What is translation?

Translation moves every point of an object by the same displacement in X and Y.

What is scaling?

Scaling changes the size of an object using scale factors along the coordinate axes.

What happens when sx = sy?

The object undergoes uniform scaling and its proportions are preserved.

Why are homogeneous coordinates used?

They allow 2D translation to be represented using matrix multiplication with a 3Ã—3 matrix.

What does a negative translation mean?

It moves the object in the negative direction of the corresponding axis.

What is non-uniform scaling?

It uses different scale factors for X and Y, which can change the object's proportions.

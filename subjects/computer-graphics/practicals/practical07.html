Flood Fill vs Boundary Fill

Both use a seed point, but their stopping conditions are different.

01

Flood Fill

Flood Fill replaces connected pixels that match the target color.

Condition currentColor == targetColor
  1. Select a seed pixel.
  2. Read its current color.
  3. Replace the target color with the fill color.
  4. Visit neighbouring pixels.
  5. Stop when the color does not match.
02

Boundary Fill

Boundary Fill replaces pixels until a specified boundary color is reached.

Condition currentColor != boundaryColor
  1. Select a seed pixel.
  2. Check whether it is a boundary pixel.
  3. Fill the current pixel.
  4. Visit neighbouring pixels.
  5. Stop when the boundary is reached.

Recursion in Filling

A valid pixel can lead the algorithm to its neighbouring pixels.

Up Down

THEN fill(pixel)

A recursive implementation calls the same fill operation for valid neighbouring pixels. For large regions, an explicit stack or queue can be used to avoid excessive call-stack depth.

Viva Questions

Check your understanding before implementing the practical.

What is a seed point?

The starting pixel from which the filling process begins.

What is Flood Fill?

An algorithm that replaces a connected region of pixels having a specified target color.

What is Boundary Fill?

An algorithm that fills a region until its specified boundary color is reached.

What is 4-connected filling?

It considers the left, right, top and bottom neighbours.

What is 8-connected filling?

It considers the four direct neighbours and four diagonal neighbours.

Why can recursive filling become expensive?

A large connected region may create many recursive calls and increase stack usage.

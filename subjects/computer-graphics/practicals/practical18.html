What is HTML Canvas?

The <canvas> element provides a drawable pixel surface in the browser. JavaScript obtains a rendering context and uses it to create 2D graphics.

const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");

ctx.beginPath();
ctx.moveTo(40, 40);
ctx.lineTo(180, 100);
ctx.stroke();

Coordinate System

Animation in Canvas

Animation Loop

Canvas animation repeatedly updates the scene and redraws it. The browser's requestAnimationFrame() API is commonly used for smooth visual updates.

function animate(time) {
  update(time);
  draw();
  requestAnimationFrame(animate);

09

Common Mistakes

  • Using page coordinates directly instead of converting them to Canvas coordinates.
  • Forgetting beginPath() when creating independent paths.
  • Mixing up Canvas width/height attributes with CSS display dimensions.
  • Changing an object without redrawing the Canvas.
  • Creating an uncontrolled animation loop without requestAnimationFrame().
  • Not storing graphical objects when later interaction, selection or undo is required.
10

Viva Questions

What is HTML Canvas?

Canvas is an HTML element that provides a drawable graphics surface controlled through JavaScript.

Where is the origin of a Canvas?

The default origin is at the top-left corner, at coordinate (0, 0).

What is the purpose of getContext("2d")?

It obtains the 2D rendering context used for drawing and manipulating 2D graphics.

Why do we convert pointer coordinates?

Pointer events provide viewport coordinates, while drawing requires coordinates relative to the Canvas.

What is requestAnimationFrame()?

It schedules a callback for the browser's next repaint and is commonly used to implement smooth animation.

How can Canvas graphics become interactive?

Store graphical objects and update their geometry in response to pointer or keyboard events, then redraw the scene.

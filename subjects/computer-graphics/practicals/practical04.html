DDA Concept & Algorithm

Algorithm Steps

  1. Read the starting point (x₁, y₁) and ending point (x₂, y₂).
  2. Calculate Î”x = x₂ − x₁.
  3. Calculate Î”y = y₂ − y₁.
  4. Find Steps = max(|Î”x|, |Î”y|).
  5. Calculate Xinc = Î”x / Steps.
  6. Calculate Yinc = Î”y / Steps.
  7. Start at (x₁, y₁) and plot the pixel.
  8. Add Xinc and Yinc to generate the next point.
  9. Round the calculated coordinates to select the raster pixel.
  10. Repeat until the endpoint is reached.

09

DDA: Strengths & Limitations

✓ Advantages

  • Simple and easy to understand.
  • Uses incremental calculations.
  • Works for different line slopes.
  • Provides a clear mathematical-to-pixel connection.

! Limitations

  • Uses floating-point calculations.
  • Requires rounding for pixel selection.
  • Can be less efficient than integer-based algorithms.
  • Floating-point error can accumulate.

10

Viva & Quick Check

What is DDA?

DDA is an incremental line drawing algorithm that generates line pixels using calculated coordinate increments.

What does DDA stand for?

Digital Differential Analyzer.

Why are steps calculated using max(|Î”x|, |Î”y|)?

It ensures the dominant coordinate changes by one unit per step while the other coordinate changes proportionally.

What are Xinc and Yinc?

They are the incremental changes added to X and Y after every iteration.

Why is rounding required?

A raster display uses discrete pixel coordinates, so calculated continuous coordinates must be mapped to pixels.

What is a limitation of DDA?

It relies on floating-point arithmetic and rounding, which can introduce computational overhead and accumulated error.

What happens for a horizontal line?

Î”y is zero, so Yinc becomes zero and Y remains constant.

How is Bresenham different?

Bresenham uses an integer-based decision process for efficient pixel selection.

What is Three.js?

Three.js is a JavaScript 3D graphics library that provides higher-level abstractions for creating scenes, cameras, lights, geometries, materials and renderers.

It commonly uses WebGL as the underlying browser graphics API.

Scene

The Scene acts as the container for objects, lights and other elements that will be rendered.

const scene = new THREE.Scene();
scene.add(mesh);

Camera

A camera defines what part of the 3D world is visible and how it is projected onto the screen.

const camera = new THREE.PerspectiveCamera(
  60, aspect, 0.1, 1000
);
camera.position.z = 6;

Renderer

The renderer converts the scene from its 3D representation into pixels displayed by the browser.

const renderer = new THREE.WebGLRenderer();
renderer.setSize(width, height);
renderer.render(scene, camera);

Perspective Projection

Three.js commonly uses a perspective camera for realistic depth. Objects farther from the camera appear smaller.

Perspective idea

Screen size decreases as camera distance increases.

Field of View (FOV) controls how wide the camera sees.

Near and far clipping planes define the visible depth range.

PerspectiveCamera Parameters

new THREE.PerspectiveCamera(
  fov,
  aspect,
  near,
  far
);
  • fov: vertical field of view in degrees.
  • aspect: viewport width Ã· viewport height.
  • near: nearest visible distance.
  • far: farthest visible distance.

Three.js Program Structure

// 1. Create scene
const scene = new THREE.Scene();

// 2. Create camera
const camera = new THREE.PerspectiveCamera(
  60, aspect, 0.1, 100
);

// 3. Create geometry + material
const geometry = new THREE.BoxGeometry(2, 2, 2);
const material = new THREE.MeshStandardMaterial();
const mesh = new THREE.Mesh(geometry, material);

// 4. Add object and light
scene.add(mesh);
scene.add(light);

// 5. Render repeatedly
function animate() {
  mesh.rotation.y += 0.01;
  renderer.render(scene, camera);
  requestAnimationFrame(animate);
}
animate();

11

Common Mistakes

  • Creating a geometry but forgetting to create and assign a material.
  • Adding a mesh to the scene but not adding a camera or renderer.
  • Placing the camera inside the object or facing away from the scene.
  • Using degrees directly where Three.js expects radians for rotation.
  • Forgetting to update the renderer and camera aspect ratio after resizing.
  • Creating a scene with lighting-dependent materials but no suitable light.
  • Starting multiple animation loops accidentally.

Viva Questions

What is Three.js?

Three.js is a JavaScript library used to create and display 3D graphics in the browser.

What is the role of a scene?

The scene is the container that holds the objects, lights and other elements that will be rendered.

Why is a camera required?

The camera defines the viewpoint and projection used to convert the 3D world into a 2D image.

What is WebGL?

WebGL is a browser graphics API that provides hardware-accelerated 2D and 3D rendering through compatible graphics hardware.

What is a mesh?

A mesh combines geometry, which defines shape, with a material, which defines its appearance.

Why are lights used?

Lights illuminate surfaces for lighting-aware materials and help create depth and shading.

Why is requestAnimationFrame() used?

It schedules animation updates in synchronization with the browser's rendering cycle.

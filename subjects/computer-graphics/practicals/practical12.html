Common Mistakes

3D transformation introduces another coordinate and multiple possible rotation axes.

01

Ignoring Z

A 3D point requires X, Y and Z. Removing Z loses depth information.

02

Wrong Rotation Axis

Rotation about X, Y and Z produces different results.

03

Wrong Matrix Order

When several 3D transformations are combined, their order affects the final coordinates.

04

Forgetting Projection

A 3D object still needs a projection step before it can be represented on a 2D screen.

Viva Questions

Test your understanding of 3D transformations.

What is a 3D coordinate?

A 3D coordinate represents a point using X, Y and Z values.

What is 3D translation?

It moves an object by tx, ty and tz along the X, Y and Z axes.

What is 3D scaling?

It changes the object's size along the X, Y and Z axes using scale factors.

How many principal rotation axes are used in 3D?

Three principal axes are used: X, Y and Z.

Why is a 4Ã—4 matrix used?

Homogeneous coordinates allow 3D translation and other transformations to be represented using matrix multiplication.

What is the difference between 2D and 3D transformation?

3D transformation includes the additional Z coordinate and supports movement, scaling and rotation through three spatial axes.

What is projection?

Projection maps a 3D scene into a 2D representation suitable for display.

What is a vertex?

A vertex is a point used to define the geometry of a 3D object.

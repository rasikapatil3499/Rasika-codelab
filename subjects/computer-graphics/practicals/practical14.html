Midpoint Subdivision

Clip a line by repeatedly dividing it at its midpoint and testing the resulting segments.

02

Midpoint Subdivision Concept

The line is divided into two halves using the midpoint. Each half is then tested independently.

Midpoint Formula

Xm = (x₁ + x₂) / 2
Ym = (y₁ + y₂) / 2

The midpoint lies exactly halfway between the two endpoints.

Why Subdivide?

If a complete segment is known to be outside the clipping region, it can be discarded. If a segment is completely inside, it can be accepted.

When the endpoints are on different sides of the boundary, subdivision narrows the search for the intersection.

1

Check endpoints

Determine whether each endpoint is inside or outside.

2

Accept / reject

Accept a fully visible segment or reject a fully invisible one.

3

Find midpoint

Calculate the midpoint of the uncertain segment.

4

Repeat

Continue subdivision until the visible boundary location is sufficiently close.

03

Clipping Tests

Every subdivision produces a smaller line segment that can be classified again.

Inside Test xmin ≤ x ≤ xmax

and

ymin ≤ y ≤ ymax
Trivial Accept Both endpoints inside

The segment is completely visible.

Trivial Reject Both endpoints outside on the same side

The segment cannot cross the window.

Important: Unlike Cohen-Sutherland, midpoint subdivision does not directly compute a boundary intersection using a slope equation. It approaches the boundary by repeatedly halving the uncertain segment.
04

Algorithm

A simple recursive strategy for line clipping.

01

Start with P₁ and P₂

Take the two endpoints of the original line.

02

Classify endpoints

Check whether each endpoint is inside or outside the clipping window.

03

Accept or reject

If the segment is clearly inside, accept it. If it is clearly outside on the same side, reject it.

04

Calculate midpoint

Compute M = ((x₁+x₂)/2, (y₁+y₂)/2).

05

Subdivide

Test P₁→M and M→P₂ separately.

06

Repeat

Continue until the visible portion is determined or the maximum subdivision depth is reached.

05

Worked Calculation

Consider a clipping window from (2,2) to (8,6).

Line: P₁(1,3) → P₂(10,5)

01

P₁(1,3) is outside on the LEFT. P₂(10,5) is outside on the RIGHT.

02

Find midpoint: M = ((1+10)/2, (3+5)/2) = (5.5,4).

03

M(5.5,4) lies inside the clipping window, so the segment around M contains visible geometry.

04

Subdivide P₁→M and M→P₂. Continue halving the outside/inside transitions.

05

After repeated subdivision, the left boundary approaches approximately (2,3.22).

06

The right boundary approaches approximately (8,4.56).

07

Final visible segment ≈ (2,3.22) → (8,4.56).

10

Common Mistakes

Wrong midpoint

Use the average of both x-coordinates and both y-coordinates.

Stopping too early

Low subdivision depth gives only a rough boundary approximation.

Ignoring rejection

A segment completely outside on the same side can be discarded without endless subdivision.

Mixing coordinate systems

Keep mathematical coordinates separate from screen-pixel coordinates during calculations.

Midpoint Subdivision vs Cohen-Sutherland

Both solve line clipping, but they approach the problem differently.

Feature Midpoint Subdivision Cohen-Sutherland
Main ideaRepeatedly divide the segmentUse region codes and boundary intersections
Midpoint calculationCore operationNot required for the main algorithm
Boundary resultApproximated through subdivisionCalculated directly using intersection equations
Learning valueGood for recursion and geometric reasoningGood for bitwise region classification
12

Viva Questions

Check your understanding before moving to polygon clipping.

What is midpoint subdivision?

It is a line-clipping approach that repeatedly divides a line segment at its midpoint and classifies the resulting segments.

What is the midpoint formula?

M = ((x₁+x₂)/2, (y₁+y₂)/2).

Why is recursion useful here?

Each uncertain segment can be divided into smaller segments and processed using the same clipping logic.

When can a segment be accepted?

When it is completely inside the clipping window.

When can a segment be rejected?

When it is completely outside and cannot intersect the clipping window.

What happens when one endpoint is inside and one is outside?

The segment is subdivided so that the boundary transition can be located progressively.

What does increasing subdivision depth do?

It improves the approximation of the clipping boundary but requires more subdivision steps.

How is it different from Cohen-Sutherland?

Midpoint subdivision searches for the boundary by repeated halving, while Cohen-Sutherland uses outcodes and direct boundary intersection calculations.

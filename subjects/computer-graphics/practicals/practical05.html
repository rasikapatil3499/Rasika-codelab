Why Bresenham?

A mathematical line is continuous, while a raster display must choose discrete pixels. Bresenham makes that choice efficiently using a decision parameter.

▫

Raster Display

A screen is a grid of discrete pixels. A line must therefore be converted into a sequence of pixel positions.

Bresenham evaluates a decision value to determine which candidate pixel is closer to the ideal mathematical line.

02

Bresenham Concept & Algorithm

For the basic positive-slope case, each iteration chooses between the East (E) and North-East (NE) candidate pixels.

Algorithm Steps

  1. Read the starting point (x₁, y₁) and ending point (x₂, y₂).
  2. Calculate Î”x = x₂ − x₁ and Î”y = y₂ − y₁.
  3. For the basic case, take 0 ≤ m ≤ 1 and move from left to right.
  4. Initialize the decision parameter using p₀ = 2Î”y − Î”x.
  5. Plot the current pixel.
  6. If p < 0, choose the East pixel and update the decision parameter.
  7. If p ≥ 0, choose the North-East pixel and update the decision parameter.
  8. Repeat until the endpoint is reached.
  9. For other slope directions, the coordinate update rules are adapted to the octant.

What Does the Decision Parameter Do?

When P < 0

The ideal line is closer to the East candidate, so the algorithm selects E and advances horizontally.

When P ≥ 0

The ideal line is closer to the North-East candidate, so the algorithm selects NE and advances in both X and Y.

10

Advantages & Limitations

Advantages

  • Uses efficient integer-based calculations in the classic formulation.
  • Provides a clear decision rule for choosing pixels.
  • Well suited to raster line generation.
  • Produces a consistent pixel approximation.

Limitations

  • The basic derivation is easiest for one slope range.
  • Other octants require adapted coordinate update rules.
  • The decision logic is less intuitive initially than simple DDA increments.
11

Viva & Quick Check

What is Bresenham's line drawing algorithm?

It is a raster line algorithm that selects pixels using an incremental decision parameter.

What is the decision parameter?

It is the value used to decide which candidate pixel should be selected next.

Why is Bresenham efficient?

The classic line formulation relies on incremental integer arithmetic instead of repeated floating-point interpolation.

What are E and NE?

For the basic positive-slope case, E is the horizontal candidate and NE is the diagonal candidate.

What happens when P is negative?

The basic rule selects E and updates the decision parameter with the corresponding incremental term.

How is Bresenham different from DDA?

DDA uses coordinate increments and rounding, while Bresenham uses a decision parameter to choose raster pixels.

What is the initial decision parameter?

For the basic case 0 ≤ m ≤ 1, p₀ = 2Î”y − Î”x.

Why are octants important?

The basic derivation assumes a particular direction and slope range, so other line directions require adapted update rules.

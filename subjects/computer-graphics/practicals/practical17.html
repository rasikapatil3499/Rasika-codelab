What Is a B-Spline?

B-Spline means Basis Spline. It represents a curve as a weighted combination of control points and basis functions.

Key Components

  • Control points: define the shape.
  • Degree p: defines the polynomial degree.
  • Knot vector: controls parameter intervals.
  • Basis functions: determine point weights.

Why Use B-Splines?

A high-degree Bezier curve can make every control point influence the entire curve. B-Splines provide local control: changing a control point generally affects only a portion of the curve.

Important Properties

Local Control

A control point influences only a limited portion of the curve, depending on the degree and knot vector.

Piecewise Polynomial

A B-Spline is made from polynomial curve pieces joined across knot intervals.

Partition of Unity

Within the valid parameter domain, the active B-Spline basis functions sum to 1.

Knot Multiplicity

Repeated knots influence continuity and endpoint behavior. Clamped vectors repeat endpoint knots to make the curve reach the end control points.

Common Mistakes

Invalid degree

The degree must be less than the number of control points.

Wrong knot count

For n + 1 control points and degree p, use n + p + 2 knots.

Ignoring parameter domain

The valid curve domain depends on the knot vector. Do not assume every knot value is a valid curve parameter.

Zero denominator errors

Repeated knots can create zero denominators in Cox-de Boor recursion; those terms contribute zero.

Viva Questions

Check your understanding before moving to interactive HTML Canvas graphics.

What does B-Spline stand for?

Basis Spline.

What are the main components of a B-Spline?

Control points, degree, knot vector and B-Spline basis functions.

What is the Cox-de Boor formula?

It is the recursive definition used to calculate B-Spline basis functions.

What is a knot vector?

An ordered sequence of parameter values that divides the curve domain into knot spans.

Why is local control important?

Moving one control point can modify only a portion of the curve instead of changing the entire curve.

How many knots are needed?

With n + 1 control points and degree p, the standard relation is m + 1 = n + p + 2.

What is a clamped knot vector?

A knot vector with repeated endpoint knots, commonly used so the curve reaches the first and last control points.

Where are B-Splines used?

They are widely used in CAD, computer graphics, animation, font design and geometric modeling.

Bresenham Circle Drawing

Generate a circle using a decision parameter and eight-way symmetry.

CircleSymmetryAnimation Decision Parameter Pixel-by-Pixel
01

Why Bresenham Circle?

Convert a continuous mathematical circle into a clean raster pattern.

⭕

Ideal Circle

A mathematical circle contains infinitely many points. A raster display can only illuminate discrete pixels.

🎯

Decision Based

The algorithm chooses the next pixel using an integer decision parameter instead of repeatedly evaluating the circle equation.

✦

Eight-Way Symmetry

Only one octant needs to be calculated. Each point can generate up to eight symmetric pixels.

Center + Radius→Calculate One Octant→Decision P→8-Way Symmetry→Raster Circle
02

Circle Geometry & Eight-Way Symmetry

One calculated point is mirrored across the eight octants.

Mathematical Circle

x² + y² = r²

For a circle centered at (xc, yc), a calculated point (x, y) produces:

(xc + x, yc + y) (xc - x, yc + y) (xc + x, yc - y) (xc - x, yc - y) (xc + y, yc + x) (xc - y, yc + x) (xc + y, yc - x) (xc - y, yc - x)
8-WAY SYMMETRY
03

Bresenham Circle Algorithm

Follow the decision parameter and select E or SE at each step.

01

Set the center (xc, yc) and radius r.

02

Initialize x = 0, y = r.

03

Initialize the decision parameter p = 3 - 2r.

04

Plot the eight symmetric points for (x, y).

05

If p < 0, choose E and update p = p + 4x + 6.

06

If p ≥ 0, choose SE, decrement y, and update p = p + 4(x-y) + 10.

07

Increment x.

08

Repeat while x ≤ y.

Advantages & Limitations

Know when Bresenham Circle is useful.

✓ Advantages

  • Uses integer arithmetic.
  • Efficient for raster displays.
  • Eight-way symmetry reduces computation.
  • Easy to visualize pixel-by-pixel.

! Limitations

  • Produces a raster approximation, not a continuous circle.
  • Pixel quality depends on resolution.
  • Basic teaching form focuses on one octant and symmetry.
11

Viva Questions

Check whether you understand the algorithm, not just the output.

Why is eight-way symmetry used?

A circle is symmetric about both axes and the diagonals, so one calculated point can be reflected to eight octants.

What is the decision parameter?

It is an integer value used to decide whether the next raster pixel should move E or SE.

Why calculate only one octant?

The remaining octants can be obtained through symmetry, reducing computation.

What happens when P < 0?

The algorithm selects E and updates the decision parameter accordingly.

What happens when P ≥ 0?

The algorithm selects SE, decreases y, and updates P.

Why is Bresenham suitable for raster graphics?

Its decision process can be implemented using efficient integer arithmetic.

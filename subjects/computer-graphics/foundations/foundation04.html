What is a Graphics Primitive?

A graphics primitive is a basic geometric element that a graphics system can draw directly or use as a building block for more complex objects.

Common primitives include points, lines, circles, ellipses, rectangles, triangles and polygons. More complex graphics can be constructed by combining these simple elements.

Think of primitives as building blocks.

A house can be represented using rectangles, triangles and lines. A character can be constructed from circles, polygons and curves.

COMMON ERRORS

Watch out for these mistakes.

Wrong Coordinate Order

Keep the representation as (x, y), not (y, x).

Missing Vertices

A polygon needs an ordered collection of vertices.

Open Polygon

Remember to connect the last vertex back to the first when required.

Wrong Radius

A circle requires a centre and a radius, not a diameter as the radius.

Screen Coordinates

Check the coordinate convention before drawing a shape.

Ignoring Geometry

Calculate dimensions and positions before implementing the drawing.

01 · CONCEPT

What is Computer Graphics?

Computer Graphics refers to the use of computers to create, store, manipulate and display images, diagrams, animations and other visual information.

Instead of treating an image only as something to look at, Computer Graphics studies how that visual information is represented mathematically and how a computer generates the final image.

Think of it this way:

Computer Graphics connects mathematics + data + algorithms + hardware to produce visual output.

WHY IT MATTERS

Graphics are everywhere.

Computer Graphics is not limited to drawing programs. It is a foundation for many technologies students use every day.

02 · TYPES

Different ways to represent graphics.

Two important ways of understanding graphics are by dimensionality and by representation.

DIMENSION

2D Graphics

Graphics represented primarily on a two-dimensional plane using X and Y coordinates.

Point P(x, y)
  • Lines and polygons
  • Images and interfaces
  • Charts and diagrams
DIMENSION

3D Graphics

Graphics that represent objects in three dimensions using X, Y and Z coordinates.

Point P(x, y, z)
  • 3D models
  • Games and simulation
  • Virtual environments
03 · REPRESENTATION

Raster or Vector?

This distinction becomes important when studying pixels, image formats and graphics storage.

Feature Raster Graphics Vector Graphics
Basic representation Grid of pixels Geometric shapes and mathematical paths
Best suited for Photographs and detailed images Logos, diagrams and scalable illustrations
Scaling Can lose quality when enlarged Can scale without the same pixelation
Examples JPEG, PNG, BMP, GIF SVG

KEY TERMINOLOGY

Words you should know.

Pixel

The smallest addressable picture element in a raster image.

Resolution

The number of pixels used to represent an image or display.

Raster

A graphics representation based on a grid of pixels.

Vector

A graphics representation based on geometric descriptions.

Rendering

The process of generating a visual image from graphical data.

Frame Buffer

Memory containing data used to produce the displayed image.

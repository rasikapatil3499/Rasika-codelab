01 Â· CONCEPT

What does a graphics file store?

A graphics file stores information required to reconstruct an image. Depending on the representation, this information may describe individual pixels or geometric objects.

The two fundamental approaches are raster graphics and vector graphics.

Raster

Represents an image as a rectangular grid of pixels. Each pixel contains color information.

Vector

Represents graphics using mathematical descriptions of shapes such as paths, lines, curves and polygons.

05 Â· COMMON FILE FORMATS

Know what each format is designed for.

File formats make different trade-offs between quality, compression, compatibility, transparency and storage size.

BMP

BMP

Bitmap format with a relatively straightforward pixel-based representation. Files can be large because compression is limited or absent in common BMP usage.

GIF

GIF

Raster format supporting a limited color palette and simple animation. Commonly used for short animated graphics.

JPG

JPEG / JPG

Common raster format using lossy compression. Well suited to photographs and images where smaller files are useful.

PNG

PNG

Lossless raster format with support for transparency. Useful for graphics, screenshots and images requiring preserved pixel detail.

TIF

TIFF

Flexible raster format commonly associated with high-quality imaging, scanning and publishing workflows.

SVG

SVG

Vector format based on geometric descriptions. It is useful for scalable icons, diagrams, logos and web graphics.

WEBP

WebP

Modern image format designed for efficient web delivery, supporting both lossy and lossless compression.

PCX

PCX

Older raster graphics format associated with early PC-based graphics software. It is mainly useful as a legacy format to understand historically.

06 Â· COMPRESSION

Why compress an image?

Compression reduces the amount of data required to store or transmit an image.

LOSSLESS

Preserve the original data.

Lossless compression reduces file size while allowing the original encoded information to be reconstructed.

Examples

PNG is a common lossless image format. Some TIFF configurations can also use lossless compression.

LOSSY

Trade some information for smaller files.

Lossy compression removes information considered less important to achieve a smaller representation.

Example

JPEG commonly uses lossy compression and is widely used for photographs.

07 Â· CHOOSE A FORMAT

Match the format to the task.

Photograph

JPEG is often a practical choice when compact file size is important.

Transparent Web Graphic

PNG is useful when lossless quality and transparency are required.

Scalable Logo

SVG is suitable when the graphic is naturally represented by geometry.

Simple Animation

GIF can be used for simple, limited-color animated graphics.

High-Quality Imaging

TIFF is commonly used in scanning, publishing and imaging workflows.

Legacy Graphics

PCX is mainly encountered when working with older graphics systems.

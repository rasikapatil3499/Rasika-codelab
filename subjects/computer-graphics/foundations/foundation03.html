01 Â· CONCEPT

What is a Coordinate?

A coordinate is a numerical description of the position of a point. In two-dimensional graphics, a point is commonly represented as (x, y).

The first value represents the horizontal position and the second value represents the vertical position. Together, they identify a point within the coordinate system.

Basic representation

Point P = (x, y)

02 Â· COORDINATE SYSTEM

Start with the origin and axes.

A standard Cartesian coordinate system uses an origin and two perpendicular axes to describe positions on a plane.

01

Origin

The point where the X-axis and Y-axis intersect. It is represented by (0, 0).

02

X-axis

The horizontal axis. Positive X values move to the right and negative X values move to the left.

03

Y-axis

The vertical axis. In the standard Cartesian system, positive Y moves upward and negative Y moves downward.

04

Quadrants

The two axes divide the plane into four regions, called Quadrants I, II, III and IV.

06 Â· SCREEN COORDINATES

Why does the screen feel different?

Graphics systems often use a screen coordinate system in which the origin is at the top-left and Y increases downward.

COMMON ERRORS

Watch out for these mistakes.

Mixing X and Y

Remember: (x, y) means horizontal position first, vertical position second.

Forgetting the Origin

Coordinates are interpreted relative to the coordinate system's origin.

Ignoring Y Direction

Check whether your graphics system increases Y upward or downward.

Wrong Quadrant

Determine the signs of both coordinates before identifying the quadrant.

Off-by-One Errors

Pixel indices and geometric coordinates do not always use the same conventions.

Incorrect Mapping

Keep coordinate-system transformation separate from the drawing algorithm.

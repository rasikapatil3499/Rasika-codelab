How Does an Object Become Pixels?

Graphics begin as mathematical descriptions of objects. Before we see them on a screen, they pass through coordinates, transformations, viewing, clipping and rasterization.

01 · BIG IDEA

The screen does not directly understand a triangle.

A graphics program may describe a triangle using three vertices. Those vertices are mathematical coordinates. The graphics system must process the geometry and determine how it maps onto the discrete pixel grid of the final image.

Core idea

Object → Coordinates → Transform → View → Clip → Rasterize → Pixel

03 · COORDINATES

Everything starts with position.

OBJECT SPACE

Describe the object.

P = (x, y)

A point or vertex can be described using coordinates. A collection of vertices can define a line, triangle or polygon.

SCREEN SPACE

Describe its pixel location.

Pixel = (xₛ, yₛ)

After viewing and mapping, the geometry is related to the coordinate system used by the final raster image.

04 · TRANSFORMATION

Change the object's position, size or orientation.

T

Translation

Moves an object from one location to another without changing its basic size or orientation.

S

Scaling

Changes the size of an object by multiplying coordinate values by scale factors.

R

Rotation

Changes the orientation of an object around a selected origin or pivot.

C

Composite

Combines multiple transformations. The order of operations can affect the final result.

05 · WORKED CALCULATION

See a translation mathematically.

Suppose a point is moved by a translation vector.

GIVEN

P(3, 4)

Translation = (5, 2)

Tx = 5
Ty = 2
CALCULATE
x' = x + Tx
y' = y + Ty
x' = 3 + 5 = 8
y' = 4 + 2 = 6

P' = (8, 6)
06 · CLIPPING

Only the visible part should continue.

A viewing window defines the region that should be considered for the final image. Clipping determines which parts of graphical primitives lie inside or outside that region.

WINDOW

Visible region

xmin ≤ x ≤ xmax
ymin ≤ y ≤ ymax

A point satisfying these conditions lies inside a rectangular clipping window.

OUTSIDE

Discard or clip the portion

Why?

Processing invisible geometry is unnecessary for the final view. Clipping reduces the geometry considered for display.

08 · RASTERIZATION

Geometry meets a discrete pixel grid.

Rasterization determines the raster representation of geometric primitives. This is where the mathematical object is connected to individual screen locations.

09 · CONNECT THE CONCEPTS

These foundations lead directly to your practicals.

DDA

Line Rasterization

Converts a mathematical line into a sequence of raster positions using incremental calculations.

BRE

Bresenham

Uses an efficient decision approach to select pixels for rasterizing lines and circles.

2D

Transformations

Translation, scaling, rotation, reflection and shear modify object coordinates.

CLIP

Clipping

Cohen-Sutherland and other algorithms determine visible portions of graphical primitives.

3D

3D Graphics

3D objects pass through transformations and viewing before appearing as a 2D image.

CURVE

Curves

Bezier and B-Spline representations define smooth geometric curves that can ultimately be rasterized.

10 · TERMINOLOGY

Words you should know before starting algorithms.

Object

A graphical entity represented by geometry and visual properties.

Transformation

A mathematical operation that changes an object's position, size or orientation.

Viewing Window

The region of the scene selected for viewing.

Clipping

Removing or limiting portions outside the visible region.

Rasterization

Converting geometric information into raster-oriented image data.

Pixel

A discrete picture element used in a raster image.

COMMON ERRORS

Keep the pipeline clear.

Wrong Transformation Order

Composite transformations may produce different results when their order changes.

Confusing Window and Viewport

A window selects a region of the scene; a viewport defines where it is displayed.

Geometry ≠ Pixel Data

Geometric coordinates describe an object; rasterization connects that geometry to pixels.

Ignoring Clipping

Not every part of a scene is necessarily inside the visible region.

Coordinate-System Confusion

Keep mathematical, world, view and screen coordinate conventions distinct.

Skipping the Mathematics

The algorithms that follow depend heavily on coordinate and geometric reasoning.

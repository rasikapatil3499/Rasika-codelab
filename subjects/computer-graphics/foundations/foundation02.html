01 · CONCEPT

What is a Pixel?

The word pixel comes from “picture element”. In a raster image, an image is represented as a rectangular grid of pixels.

Each pixel has a position in the image and stores visual information such as color or intensity. When many pixels are arranged together, they form the complete image we see.

Think of a pixel as one cell in an image grid.

One pixel alone contains very little visual information. Millions of pixels together can represent a detailed photograph, interface, diagram or rendered scene.

03 · RESOLUTION

What does resolution mean?

Resolution describes the number of pixels used along the width and height of a raster image or display.

EXAMPLE

1920 × 1080

A display with 1920 pixels horizontally and 1080 pixels vertically contains:

Total Pixels 1920 × 1080 = 2,073,600
IMPORTANT

More pixels ≠ automatically better

Higher resolution can provide more image detail, but perceived quality also depends on display size, viewing distance, pixel density, image quality and other factors.

04 · CALCULATE

Calculate the total number of pixels.

For a raster image, multiply its width by its height.

Worked Example

Suppose an image has a resolution of 1280 × 720 pixels.

Total Pixels = Width × Height
Width = 1280 pixels
Height = 720 pixels

Total Pixels = 1280 × 720
Total Pixels = 921,600
Answer

The image contains 921,600 pixels.

05 · ASPECT RATIO

Width and height have a relationship.

Aspect ratio describes the proportional relationship between the width and height of an image or display.

FORMULA

Aspect Ratio

Aspect Ratio = Width : Height

For 1920 × 1080:

1920 : 1080
Divide both by 120

= 16 : 9
WHY IT MATTERS

Shape of the image

Maintaining the correct aspect ratio prevents an image from appearing stretched or compressed.

  • 16:9 — common widescreen format
  • 4:3 — older display and video format
  • 1:1 — square image
06 · COLOR DEPTH

How much information can one pixel store?

Color depth describes the number of bits used to represent the color information of a pixel.

Bits per Pixel Possible Values Typical Meaning
1 bit 2 Two possible states
8 bits 256 256 possible values
24 bits 2²⁴ = 16,777,216 True-color RGB representation
32 bits 2³² possible combinations Often includes an alpha channel
Number of possible values = 2ⁿ

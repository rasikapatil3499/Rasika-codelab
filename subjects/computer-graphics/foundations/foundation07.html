What does â€œdrawingâ€ mean in computer graphics?

A computer does not draw an object in the same way a person draws on paper. A graphics application provides data such as coordinates, shapes, colors, textures and other rendering information.

A rendering system processes this information and eventually produces pixel values that can be presented on a display.

Rendering

Rendering is the process of generating a visual image from graphical data such as geometry, color, lighting and other scene information.

03 Â· CPU & GPU

Who does the graphics work?

CPU

General-purpose processing

The CPU executes program instructions and can prepare graphics data, application logic and rendering commands.

Think: application control

The CPU is responsible for broad program execution and coordinating many parts of the application.

GPU

Graphics-oriented processing

The GPU is designed to process graphics workloads efficiently, especially operations that can be performed in parallel.

Think: graphics processing

Modern GPUs contain many processing resources optimized for highly parallel workloads.

09 Â· TERMINOLOGY

Words you should know.

Rendering

Generating a visual image from graphics data.

Rasterization

Converting geometric primitives into raster-oriented image data.

GPU

Processor designed for graphics and other highly parallel workloads.

Frame Buffer

Memory used to hold image data for a frame.

Pixel

A discrete picture element in a raster image.

Graphics API

Interface that lets software communicate graphics operations to a graphics system.

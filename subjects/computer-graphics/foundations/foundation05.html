How Does Color Work?

A pixel is more than a position. It also stores color information. Learn how RGB, CMYK, grayscale, alpha and color depth turn numerical values into visible colors.

01 · CONCEPT

How is a color stored?

Digital graphics represent color using numerical values. Instead of storing a color as a name such as "orange", a graphics system stores component values that describe the color.

In the commonly used RGB model, a color is represented using three channels: Red, Green and Blue.

RGB representation

RGB = (R, G, B), where each component commonly ranges from 0 to 255 in an 8-bit-per-channel representation.

02 · RGB COLOR MODEL

Three channels create millions of colors.

Each RGB channel contributes a different amount of light. Combining their intensities produces the final color.

R

Red

Controls the intensity of red light. 0 means none and 255 represents maximum intensity in an 8-bit channel.

G

Green

Controls the intensity of green light from 0 to 255 in an 8-bit channel.

B

Blue

Controls the intensity of blue light from 0 to 255 in an 8-bit channel.

RGB

Combination

Different channel values combine to produce the final displayed color.

05 · COLOR DEPTH

How many colors can a pixel store?

Color depth describes how many bits are available to represent color information.

GENERAL FORMULA

Number of possible values

Number of values = 2ⁿ
n = number of bits
24-BIT RGB

Three 8-bit channels

Red = 8 bits
Green = 8 bits
Blue = 8 bits

Total = 8 + 8 + 8
Total = 24 bits
Possible colors

2²⁴ = 16,777,216 colors

06 · GRAYSCALE

Color is not always three-channel.

A grayscale image represents intensity from black through shades of gray to white.

Black

Minimum intensity.

Gray

Intermediate intensity.

White

Maximum intensity.

8-bit grayscale

2⁸ = 256 possible intensity levels.

Single channel

Grayscale can use one intensity value per pixel.

Useful for

Scanning, image processing, thresholding and scientific images.

07 · RGB VS CMYK

Different systems are designed for different purposes.

Feature RGB CMYK
Full form Red, Green, Blue Cyan, Magenta, Yellow, Key/Black
Model Additive Subtractive
Common use Screens and digital displays Printing
Basic idea Combines light Uses inks that absorb light
08 · ALPHA CHANNEL

Color can also contain transparency.

An alpha channel stores transparency information separately from the RGB color channels.

RGBA

RGBA = (R, G, B, A)
R = Red
G = Green
B = Blue
A = Alpha / transparency

Example

RGB = (255, 138, 0)
Alpha = 128
Meaning

The color is orange with partial transparency when represented using a conventional 8-bit alpha channel.

COMMON ERRORS

Watch out for these mistakes.

Confusing RGB with CMYK

RGB is commonly associated with screens, while CMYK is commonly used for printing.

Wrong Channel Range

For standard 8-bit RGB, each channel ranges from 0 to 255.

Forgetting Color Depth

Total possible combinations depend on the number of bits available.

Alpha Is Not a Color

Alpha represents transparency information rather than red, green or blue intensity.

Mixing Bits and Bytes

Remember that 8 bits make 1 byte.

Ignoring Representation

The same visual color can be represented using different numerical formats.

QUICK SUMMARY

Remember these five ideas.

01 RGB uses three channels

Red, green and blue values combine to produce colors.

02 8-bit channel = 0–255

Each channel has 256 possible values in standard 8-bit RGB.

03 24-bit RGB = 2²⁴

That gives 16,777,216 possible RGB combinations.

04 Alpha controls transparency

RGBA adds an alpha channel to RGB.

05 Color becomes pixel data

Numerical color values are ultimately represented as pixel information.

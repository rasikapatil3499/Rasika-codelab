CONCEPT

Understanding File Handling

What is File Handling?

File handling is the process of storing data in files and retrieving that data later. C++ provides file stream classes through the <fstream> header.

01

ofstream

Used to open a file for output and write data into it.

02

ifstream

Used to open a file for input and read data from it.

03

fstream

Provides a file stream that can support both input and output operations.

04

close()

Closes an open file stream after the required operation is complete.

Real-Life Example

When a student-management program saves a student's details, the information should remain available after the program closes. A file provides persistent storage so the program can read those details again later.

Where and How Is File Handling Used?

Student Records

Store roll numbers, names, marks and other academic records.

Employee Records

Save employee IDs, names and salary information.

Reports & Logs

Store generated reports, application logs and text information.

Data Processing

Read existing files to search, count, copy or transform their contents.

TOPIC 03

File Copy & Processing

Copy files and process their contents through sequential character or word reading.

PROBLEM

Copy One File to Another

Problem Statement

Write a C++ program to copy the contents of one text file into another file using file streams.

Theory / Concept

A source file can be opened with ifstream and a destination file with ofstream. Characters or lines are read from the source and written to the destination.

SYNTAX

File Handling Syntax

ifstream source("source.txt");
ofstream destination("copy.txt");

char ch;
while (source.get(ch))
{
    destination.put(ch);
}

Algorithm

  1. Open the source file for reading.
  2. Open the destination file for writing.
  3. Read each character from the source.
  4. Write the character to the destination.
  5. Close both files.

C++ Program

#include <iostream>
#include <fstream>
using namespace std;

int main()
{
    ifstream source("source.txt");
    ofstream destination("copy.txt");

    char ch;

    while (source.get(ch))
    {
        destination.put(ch);
    }

    source.close();
    destination.close();

    cout << "File copied successfully.";

    return 0;
}

Expected Output

File copied successfully.
VISUAL EXPLANATION

How Data Moves

ProgramMemory / variables
→
ofstreamFile stream
→
File.txt storage

get() reads one character from the source and put() writes it to the destination until the source reaches EOF.

Program Explanation

  • Use ifstream for the source.
  • Use ofstream for the destination.
  • Close both streams.

Real-Life Connection

File copying is used in backup utilities, document duplication and data migration.

Key Points

  • Use ifstream for the source.
  • Use ofstream for the destination.
  • Close both streams.

Common Errors

Wrong stream direction

Source is input; destination is output.

Skipping characters

Use get()/put() to copy every character.

Same filename

Avoid opening source and destination as the same file.

PROBLEM

Count Characters and Words

Problem Statement

Write a C++ program to read a text file and count the number of characters and words.

Theory / Concept

A file can be processed sequentially while maintaining counters. isspace() can help identify whitespace separating words.

SYNTAX

File Handling Syntax

ifstream file("data.txt");

char ch;
int characters = 0;
int words = 0;
bool inWord = false;

while (file.get(ch))
{
    characters++;
    // detect word boundaries
}

Algorithm

  1. Open the text file.
  2. Initialize character and word counters.
  3. Read each character.
  4. Count every character.
  5. Detect transitions into words using whitespace.
  6. Display the totals.
  7. Close the file.

C++ Program

#include <iostream>
#include <fstream>
#include <string>
#include <cctype>
using namespace std;

int main()
{
    ifstream file("data.txt");

    char ch;
    int characters = 0;
    int words = 0;
    bool inWord = false;

    while (file.get(ch))
    {
        characters++;

        if (!isspace(static_cast<unsigned char>(ch)))
        {
            if (!inWord)
            {
                words++;
                inWord = true;
            }
        }
        else
        {
            inWord = false;
        }
    }

    file.close();

    cout << "Characters: " << characters << endl;
    cout << "Words: " << words << endl;

    return 0;
}

Expected Output

Characters: 25
Words: 4
VISUAL EXPLANATION

How Data Moves

ProgramMemory / variables
→
ifstreamFile stream
→
File.txt storage

The program counts every character and increments the word count when it enters a non-whitespace sequence.

Program Explanation

  • Count every character read.
  • Use whitespace to detect word boundaries.
  • Keep an inWord state to avoid counting letters inside the same word repeatedly.

Real-Life Connection

Text analysis tools use similar sequential scanning to calculate document statistics.

Key Points

  • Count every character read.
  • Use whitespace to detect word boundaries.
  • Keep an inWord state to avoid counting letters inside the same word repeatedly.

Common Errors

Counting every letter as a word

Count only transitions into a word.

Ignoring spaces incorrectly

Use whitespace detection.

Missing cctype

Include <cctype> for isspace().

PROBLEM

Search a Word in a File

Problem Statement

Write a C++ program to search for a given word in a text file and report whether it is found.

Theory / Concept

A file can be searched sequentially by reading words and comparing each word with the target word.

SYNTAX

File Handling Syntax

ifstream file("data.txt");
string word;

while (file >> word)
{
    if (word == target)
    {
        // found
    }
}

Algorithm

  1. Open the file.
  2. Set the target word.
  3. Read words one by one.
  4. Compare each word with the target.
  5. Report whether a match was found.
  6. Close the file.

C++ Program

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main()
{
    ifstream file("data.txt");

    string target = "C++";
    string word;
    bool found = false;

    while (file >> word)
    {
        if (word == target)
        {
            found = true;
            break;
        }
    }

    file.close();

    if (found)
        cout << "Word found.";
    else
        cout << "Word not found.";

    return 0;
}

Expected Output

Word found.
VISUAL EXPLANATION

How Data Moves

ProgramMemory / variables
→
ifstreamFile stream
→
File.txt storage

The program reads tokens from the file and compares each one with the target word until a match is found or the file ends.

Program Explanation

  • Read words sequentially.
  • Compare strings using ==.
  • Stop when a match is found.

Real-Life Connection

Search functionality is useful in document tools, log analysis and simple text-processing programs.

Key Points

  • Read words sequentially.
  • Compare strings using ==.
  • Stop when a match is found.

Common Errors

Case mismatch

The basic comparison is case-sensitive.

Punctuation

A word attached to punctuation may not exactly match.

Wrong target

Ensure the target string is what you intend to search.

PROBLEM

Student Record Management

Problem Statement

Write a C++ program to write and then read a Student object using file handling.

Theory / Concept

This combines writing and reading object data in one program. The same text-file format is used for persistence and retrieval.

SYNTAX

File Handling Syntax

in >> rollNo >> name >> marks;
in.close();

Algorithm

  1. Create a Student object.
  2. Open the file for output.
  3. Write the object's fields.
  4. Close the output stream.
  5. Open the same file for input.
  6. Read the fields into the object.
  7. Display the record.
  8. Close the input stream.

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

        cout << "Name: " << name << endl;

int main()
{
    Student s;
    s.rollNo = 102;
    s.name = "Neha";
    s.marks = 91.0f;

    s.writeToFile(out);
    out.close();

    Student loaded;

    loaded.readFromFile(in);
    in.close();

    cout << "Record read from file:" << endl;

03 — EXPLORE THE CONCEPT

Understanding Friend Functions

A friend function is a non-member function that is given special permission to access private and protected members of a class.

Theory

A friend function is a function that is not a member of a class but can access the private and protected members of that class.

The function is declared inside the class using the friend keyword. Its definition is normally written outside the class.

Friend functions are useful when an external function needs access to private data or when one function needs to work with private data belonging to more than one class.

class Demo { private: int value; public: friend void show(Demo); }; void show(Demo d) { cout << d.value; }
Class → Friend Declaration → External Function
🌍

Real-Life Example

Consider a banking application where account information is kept private inside an Account class. A separate reporting function may need controlled access to this private information to generate a report.

A friend function can provide this access without making the private data publicly accessible.

Where & How Is It Used?

Different Classes

A single friend function can access private data from two or more classes.

External Functions

A non-member function can be given special access to private class members.

Operator Overloading

Friend functions are commonly used when an operator needs access to private object data.

Basic Syntax 

class ClassName
{
private:
    int data;

public:
    friend void functionName(ClassName);
};

void functionName(ClassName obj)
{
    // access private data
}
LLO 7.1

Friend Function Using Two Different Classes

Concept

A friend function can be declared in two different classes. The same external function can then access private members of both classes.

This is useful when two objects contain related information and a common operation needs access to their private data.

PROBLEM 01

Compare Two Numbers

Problem Statement

Write a C++ program to create two classes containing private integer values. Use a common friend function to find the greater value from the two classes.

Algorithm

  1. Start.
  2. Create two classes named A and B.
  3. Declare a private integer in each class.
  4. Declare findMax() as a friend function in both classes.
  5. Accept values for both objects.
  6. Pass both objects to the friend function.
  7. Compare the private values.
  8. Display the greater value.
  9. Stop.

C++ Program 

#include <iostream>
using namespace std;

class B;

class A
{
    int valueA;

public:

    void accept()
    {
        cout << "Enter value for A: ";
        cin >> valueA;
    }

    friend void findMax(A, B);
};

class B
{
    int valueB;

public:

    void accept()
    {
        cout << "Enter value for B: ";
        cin >> valueB;
    }

    friend void findMax(A, B);
};

void findMax(A a, B b)
{
    if (a.valueA > b.valueB)
        cout << "Greater value = "
             << a.valueA;
    else
        cout << "Greater value = "
             << b.valueB;
}

int main()
{
    A a;
    B b;

    a.accept();
    b.accept();

    findMax(a, b);

    return 0;
}

Expected Output 

Enter value for A: 25
Enter value for B: 40
Greater value = 40
FRIEND FUNCTION VISUALIZATION

Two Classes → One Friend Function

The same friend function can access private data from both classes.

CLASS A 25 Private valueA
→
FRIEND FUNCTION findMax() Accesses both classes
←
CLASS B 40 Private valueB

Program Explanation

  • Classes A and B contain private data.
  • findMax() is declared as a friend in both classes.
  • It is not a member function of either class.
  • It can directly access valueA and valueB.
  • The function compares both private values.

Real-Life Connection

A comparison function can combine private information from two different objects, such as comparing two bank accounts, two products or two students.

Key Points

  • A friend function is not a member of the class.
  • It can be declared as a friend in multiple classes.
  • It can access private data of all classes that declare it as a friend.

Common Errors

Missing Friend Declaration

The function must be declared using the friend keyword in both classes.

Wrong Class Access

Make sure the correct object is used when accessing each private data member.

PROBLEM 02

Add Distance

Problem Statement

Write a C++ program to create two classes Distance1 and Distance2 containing private distance values. Use a friend function to add the distances.

Formula

Total Distance Distance 1 + Distance 2
Distance 1 Private member of class 1
Distance 2 Private member of class 2

Algorithm

  1. Start.
  2. Define classes Distance1 and Distance2.
  3. Declare private distance members.
  4. Declare addDistance() as a friend function in both classes.
  5. Accept both distances.
  6. Pass both objects to the friend function.
  7. Add the private distance values.
  8. Display the total distance.
  9. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Distance2;

class Distance1
{
    float distance1;

public:

    void accept()
    {
        cout << "Enter first distance: ";
        cin >> distance1;
    }

    friend void addDistance(Distance1, Distance2);
};

class Distance2
{
    float distance2;

public:

    void accept()
    {
        cout << "Enter second distance: ";
        cin >> distance2;
    }

    friend void addDistance(Distance1, Distance2);
};

void addDistance(Distance1 d1, Distance2 d2)
{
    cout << "Total distance = "
         << d1.distance1 + d2.distance2;
}

int main()
{
    Distance1 d1;
    Distance2 d2;

    d1.accept();
    d2.accept();

    addDistance(d1, d2);

    return 0;
}

Expected Output 

Enter first distance: 12.5
Enter second distance: 7.5
Total distance = 20
FRIEND FUNCTION VISUALIZATION

Private Data From Two Classes

DISTANCE 1 12.5 Distance1
+
DISTANCE 2 7.5 Distance2
→
FRIEND FUNCTION 20 addDistance()

Program Explanation

  • Two separate classes store private distance values.
  • addDistance() is declared as a friend in both classes.
  • The friend function directly accesses both private members.
  • The two values are added and displayed.

Real-Life Connection

A common operation can combine information stored in different objects, such as calculating total travel distance from two journeys.

Key Points

  • Friend functions can work with objects of different classes.
  • They can access private members when friendship is granted.

Common Errors

Incorrect Declaration

The friend function declaration should use the correct class names.

Wrong Member Access

Access the correct private member through its corresponding object.

PROBLEM 03

Student Marks Comparison

Problem Statement

Write a C++ program to create two classes Student1 and Student2 containing private marks. Use a common friend function to compare the marks of both students.

Algorithm

  1. Start.
  2. Create Student1 and Student2 classes.
  3. Declare marks as private members.
  4. Declare compareMarks() as a friend function in both classes.
  5. Accept marks for both students.
  6. Pass both objects to the friend function.
  7. Compare the private marks.
  8. Display the student with higher marks.
  9. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Student2;

class Student1
{
    int marks1;

public:

    void accept()
    {
        cout << "Enter marks of Student 1: ";
        cin >> marks1;
    }

    friend void compareMarks(Student1, Student2);
};

class Student2
{
    int marks2;

public:

    void accept()
    {
        cout << "Enter marks of Student 2: ";
        cin >> marks2;
    }

    friend void compareMarks(Student1, Student2);
};

void compareMarks(Student1 s1, Student2 s2)
{
    if (s1.marks1 > s2.marks2)
        cout << "Student 1 has higher marks.";
    else if (s2.marks2 > s1.marks1)
        cout << "Student 2 has higher marks.";
    else
        cout << "Both students have equal marks.";
}

int main()
{
    Student1 s1;
    Student2 s2;

    s1.accept();
    s2.accept();

    compareMarks(s1, s2);

    return 0;
}

Expected Output 

Enter marks of Student 1: 85
Enter marks of Student 2: 78
Student 1 has higher marks.
FRIEND FUNCTION VISUALIZATION

Student Objects → Common Friend Function

STUDENT 1 85 Private marks
→
COMPARE compareMarks() Friend Function
←
STUDENT 2 78 Private marks

Program Explanation

  • Both student classes contain private marks.
  • compareMarks() is a friend of both classes.
  • It receives objects of both classes.
  • It directly accesses both private marks.
  • The greater marks are identified.

Real-Life Connection

Educational systems may compare private academic data belonging to different student objects while keeping those marks private within their classes.

Key Points

  • Friendship can be granted to the same function by multiple classes.
  • The function can access private members of those classes.
  • The friend function remains an external non-member function.

Common Errors

Missing Forward Declaration

When required, declare the second class before using it in the first class's friend declaration.

Calling as Member

A friend function is not called using the object-dot syntax. Call it as a normal function.

LLO 7.2

Friend Function Using External Function

Concept

An external function is a function defined outside the class. By declaring that function as a friend, the class gives it permission to access its private members.

The function remains an independent function and is called like a normal function.

PROBLEM 01

Display Private Data

Problem Statement

Write a C++ program to create a class Student with private roll number and name. Use an external friend function to display the private data.

Algorithm

  1. Start.
  2. Create a Student class.
  3. Declare roll number and name as private members.
  4. Declare display() as a friend function.
  5. Define the function outside the class.
  6. Create a Student object.
  7. Accept student details.
  8. Pass the object to the friend function.
  9. Display the private members.
  10. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Student
{
    int rollNo;
    string name;

public:

    void accept()
    {
        cout << "Enter roll number: ";
        cin >> rollNo;

        cout << "Enter name: ";
        cin >> name;
    }

    friend void display(Student);
};

void display(Student s)
{
    cout << "\nRoll Number = "
         << s.rollNo << endl;

    cout << "Name = "
         << s.name;
}

int main()
{
    Student s;

    s.accept();

    display(s);

    return 0;
}

Expected Output 

Enter roll number: 101
Enter name: Rahul

Roll Number = 101
Name = Rahul
FRIEND FUNCTION VISUALIZATION

Private Data → External Friend

STUDENT OBJECT s rollNo + name
→
FRIEND display(s) External Function
→
OUTPUT 101 Rahul

Program Explanation

  • Student contains private data.
  • display() is declared as a friend.
  • The function is defined outside the class.
  • It can access rollNo and name.
  • The function is called normally using display(s).

Real-Life Connection

A reporting or display function may need access to private student information without becoming a member function of the Student class.

Key Points

  • Friend functions are external to the class.
  • They can access private members when declared as friends.
  • They are called like normal functions.

Common Errors

Missing friend Keyword

Use the friend keyword inside the class declaration.

Calling as Member

Call display(s), not s.display().

PROBLEM 02

Calculate Employee Salary

Problem Statement

Write a C++ program to create an Employee class containing private basic salary. Use an external friend function to calculate and display the gross salary.

Formula

HRA Basic Salary × 20%
DA Basic Salary × 10%
Gross Salary Basic + HRA + DA

Algorithm

  1. Start.
  2. Define the Employee class.
  3. Declare basic salary as a private member.
  4. Declare calculateSalary() as a friend function.
  5. Define the friend function outside the class.
  6. Create an Employee object.
  7. Accept basic salary.
  8. Calculate HRA and DA.
  9. Calculate gross salary.
  10. Display the result.
  11. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Employee
{
    float basicSalary;

public:

    void accept()
    {
        cout << "Enter basic salary: ";
        cin >> basicSalary;
    }

    friend void calculateSalary(Employee);
};

void calculateSalary(Employee e)
{
    float hra = e.basicSalary * 0.20;
    float da = e.basicSalary * 0.10;

    float gross =
        e.basicSalary + hra + da;

    cout << "\nBasic Salary = "
         << e.basicSalary << endl;

    cout << "HRA = "
         << hra << endl;

    cout << "DA = "
         << da << endl;

    cout << "Gross Salary = "
         << gross;
}

int main()
{
    Employee e;

    e.accept();

    calculateSalary(e);

    return 0;
}

Expected Output 

Enter basic salary: 30000

Basic Salary = 30000
HRA = 6000
DA = 3000
Gross Salary = 39000
FRIEND FUNCTION VISUALIZATION

Employee Data → Salary Calculation

PRIVATE DATA ₹30,000 Basic Salary
→
FRIEND FUNCTION calculateSalary() External Function
→
RESULT ₹39,000 Gross Salary

Program Explanation

  • basicSalary is private.
  • calculateSalary() is an external friend function.
  • Friendship allows it to access basicSalary.
  • HRA and DA are calculated inside the external function.
  • Gross salary is displayed.

Real-Life Connection

Payroll systems can keep salary information private inside an Employee class while an external reporting function performs salary calculations.

Key Points

  • A friend function can access private salary data.
  • The function does not become a member of Employee.
  • It can perform operations using the private data.

Common Errors

Direct Private Access

A normal external function cannot access private data unless it is declared as friend.

Wrong Function Call

Use calculateSalary(e) instead of treating the function as a member.

PROBLEM 03

Calculate Rectangle Area

Problem Statement

Write a C++ program to create a Rectangle class containing private length and breadth. Use an external friend function to calculate and display the area of the rectangle.

Formula

Area Length × Breadth
Length Private member
Breadth Private member

Algorithm

  1. Start.
  2. Define the Rectangle class.
  3. Declare length and breadth as private members.
  4. Declare calculateArea() as a friend function.
  5. Define the friend function outside the class.
  6. Create a Rectangle object.
  7. Accept length and breadth.
  8. Pass the object to the friend function.
  9. Calculate the area.
  10. Display the area.
  11. Stop.

C++ Program 

#include <iostream>
using namespace std;

class Rectangle
{
    float length;
    float breadth;

public:

    void accept()
    {
        cout << "Enter length: ";
        cin >> length;

        cout << "Enter breadth: ";
        cin >> breadth;
    }

    friend void calculateArea(Rectangle);
};

void calculateArea(Rectangle r)
{
    float area =
        r.length * r.breadth;

    cout << "\nArea = "
         << area;
}

int main()
{
    Rectangle r;

    r.accept();

    calculateArea(r);

    return 0;
}

Expected Output 

Enter length: 10
Enter breadth: 5

Area = 50
FRIEND FUNCTION VISUALIZATION

Private Dimensions → Area

10 5
Rectangle Object length = 10 breadth = 5
→
FRIEND FUNCTION calculateArea() Area = 10 × 5

Program Explanation

  • length and breadth are private members.
  • calculateArea() is declared as a friend.
  • The external function accesses both private members.
  • The area is calculated using length × breadth.

Real-Life Connection

Geometry and engineering applications can keep dimensions private inside an object while a separate calculation function accesses them through friendship.

Key Points

  • Friend functions can access private dimensions.
  • The external function is not a class member.
  • Friendship provides controlled access to private data.

Common Errors

Forgetting friend

Declare the external function using the friend keyword inside the class.

Wrong Formula

The area of a rectangle is length × breadth.

Friend Function Basics

What is a friend function?

A friend function is a non-member function that is given permission to access private and protected members of a class.

Which keyword is used to declare a friend function?

The friend keyword is used.

Is a friend function a member of the class?

No. A friend function is not a member function of the class.

Can a friend function access private members?

Yes. A friend function can directly access private and protected members of the class that declares it as a friend.

How is a friend function called?

It is called like a normal function, for example display(obj).

Friend Function Using Different Classes

Can one friend function access two classes?

Yes. The same friend function can be declared as a friend in two or more classes.

Why is a forward declaration sometimes required?

A forward declaration can be used when one class needs to be referenced before its complete definition appears.

Can a friend function compare objects of two classes?

Yes. A friend function can receive objects of different classes and access their private members if friendship has been granted.

External Friend Function

What is an external function?

An external function is a function defined outside the class. If it is declared as a friend, it can access the class's private and protected members.

Does a friend function use the dot operator?

No. A friend function is not a member function, so it is normally called as an ordinary function.

Can a friend function be overloaded?

Yes. Friend functions can be overloaded like other non-member functions.

Can friendship be inherited?

No. Friendship is not inherited by derived classes.

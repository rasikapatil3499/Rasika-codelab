TOPIC 01

Scope Resolution Operator ::

The scope resolution operator is used to specify the scope to which a variable, function or member belongs.

Theory

In C++, scope defines the region of a program where a name such as a variable or function can be accessed. The scope resolution operator :: allows the programmer to explicitly specify the scope of a name.

It is especially useful when a local variable has the same name as a global variable, when defining class member functions outside the class, and when accessing members of a namespace.

🌍

Real-Life Example

Imagine a college where both a department and the college have information with the same name. A scope identifier helps specify exactly which level of information should be accessed.

Where & How Is It Used?

Global Variables

Access a global variable when a local variable has the same name.

Class Functions

Define a class member function outside the class.

Namespaces

Access variables and functions belonging to a namespace.

PROBLEM 01

Global and Local Variables

Problem Statement

Write a C++ program to demonstrate the use of the scope resolution operator to access a global variable when a local variable has the same name.

Syntax

::variable

Algorithm

  1. Start.
  2. Declare a global variable.
  3. Declare a local variable with the same name.
  4. Display the local variable.
  5. Use :: to access the global variable.
  6. Display the global variable.
  7. Stop.

C++ Program 

#include <iostream>
using namespace std;

int number = 100;

int main()
{
    int number = 50;

    cout << "Local value = " << number << endl;
    cout << "Global value = " << ::number << endl;

    return 0;
}

Expected Output 

Local value = 50
Global value = 100
INTERACTIVE CONCEPT

Local vs Global Scope

The same variable name can exist in different scopes.

LOCAL SCOPE number = 50 number
::
GLOBAL SCOPE number = 100 ::number

Key Points

  • Local variables have local scope.
  • Global variables can be accessed using ::.
  • Scope resolution removes ambiguity.

Common Errors

Forgetting ::

Without ::, the local variable is accessed.

Same Name Confusion

Always identify which scope contains the required variable.

public:

  • They can be defined outside the class using ClassName::.

TOPIC 02

Memory Management Operators

C++ provides new and delete for dynamic memory allocation and deallocation.

Theory

Dynamic memory allocation allows a program to request memory during program execution. The new operator allocates memory dynamically, while delete releases memory that is no longer required.

Dynamic memory is useful when the amount of data required by a program is not known beforehand or when objects need to exist dynamically during execution.

🌍

Real-Life Example

Consider an online shopping cart. Products can be added when required and removed when they are no longer needed. A program can dynamically allocate and release memory for such data.

Where & How Is It Used?

Dynamic Arrays

Allocate an array when its required size is known only during execution.

Dynamic Objects

Create objects dynamically when required.

Data Structures

Dynamic memory is fundamental to structures such as linked lists and trees.

PROBLEM 01

Dynamic Integer

Problem Statement

Write a C++ program to dynamically allocate memory for an integer using the new operator, accept a value from the user, display it, and release the memory using delete.

Algorithm

  1. Start.
  2. Declare an integer pointer.
  3. Allocate memory using new.
  4. Accept a value.
  5. Display the value.
  6. Release memory using delete.
  7. Stop.

C++ Program 

#include <iostream>
using namespace std;

int main()
{
    int *ptr;

    ptr = new int;

    cout << "Enter value: ";
    cin >> *ptr;

    cout << "Value = " << *ptr;

    delete ptr;

    return 0;
}

Expected Output 

Enter value: 50
Value = 50

Key Points

  • new dynamically allocates memory.
  • A pointer stores the address of the allocated memory.
  • delete releases dynamically allocated memory.
PROBLEM 02

Dynamic Array

Problem Statement

Write a C++ program to dynamically allocate memory for an array of integers using new, accept and display the elements, and release the memory using delete[].

C++ Program 

#include <iostream>
using namespace std;

int main()
{
    int n;

    cout << "Enter number of elements: ";
    cin >> n;

    int *arr = new int[n];

    for (int i = 0; i < n; i++)
    {
        cout << "Enter element: ";
        cin >> arr[i];
    }

    cout << "Array elements: ";

    for (int i = 0; i < n; i++)
        cout << arr[i] << " ";

    delete[] arr;

    return 0;
}

Expected Output 

Enter number of elements: 3
Enter element: 10
Enter element: 20
Enter element: 30
Array elements: 10 20 30

Key Points

  • new int[n] creates a dynamic array.
  • delete[] is used to release an array.
PROBLEM 03

Dynamic Object

Problem Statement

Write a C++ program to dynamically create an object of a class using the new operator, access its data, and release the allocated memory using delete.

C++ Program 

#include <iostream>
using namespace std;

class Student
{
public:
    int marks;

    void display()
    {
        cout << "Marks = " << marks;
    }
};

int main()
{
    Student *s = new Student;

    s->marks = 85;

    s->display();

    delete s;

    return 0;
}

Expected Output 

Marks = 85

Key Points

  • Objects can be created dynamically.
  • The arrow operator accesses members through a pointer.
  • Dynamically created objects should be released when no longer required.
TOPIC 03

Manipulators

Manipulators are used to control and format input and output streams in C++.

Theory

C++ manipulators provide a convenient way to control how data is displayed. They are commonly used to set field width, control decimal precision and format floating-point values.

Common manipulators include setw(), setprecision(), fixed and endl.

🌍

Real-Life Example

Think about a student marksheet, bank statement or shopping bill. Information is arranged into aligned columns so that it is easy to read. C++ manipulators help create this kind of formatted output.

Where & How Is It Used?

Marksheet

Align student names, marks and grades into columns.

Billing System

Format product prices and totals consistently.

Reports

Create readable console-based tables and reports.

PROBLEM 01

Student Marksheet

Problem Statement

Write a C++ program to display student marks in a properly aligned tabular format using the setw() manipulator.

C++ Program 

#include <iostream>
#include <iomanip>

using namespace std;

int main()
{
    cout << setw(15) << "Name"
         << setw(10) << "Marks" << endl;

    cout << setw(15) << "Rahul"
         << setw(10) << 85 << endl;

    cout << setw(15) << "Priya"
         << setw(10) << 92 << endl;

    return 0;
}

Expected Output 

           Name     Marks
          Rahul        85
          Priya        92

Key Points

  • setw() controls the minimum field width.
  • <iomanip> is required for setw().
PROBLEM 02

Decimal Formatting

Problem Statement

Write a C++ program to accept a floating-point value and display it with exactly two digits after the decimal point using fixed and setprecision().

C++ Program 

#include <iostream>
#include <iomanip>

using namespace std;

int main()
{
    float value;

    cout << "Enter value: ";
    cin >> value;

    cout << fixed
         << setprecision(2);

    cout << "Formatted value = "
         << value;

    return 0;
}

Expected Output 

Enter value: 125.6789
Formatted value = 125.68

Key Points

  • fixed displays floating-point values in fixed notation.
  • setprecision(2) displays two digits after the decimal point when used with fixed.

Scope Resolution

What is the scope resolution operator?

It is the :: operator used to specify the scope of a name.

How do you access a global variable when a local variable has the same name?

The global variable can be accessed using the scope resolution operator, for example ::number.

How is :: used with a class?

It can be used to define a class member function outside the class, such as Student::display().

Memory Management

What is the purpose of new?

The new operator dynamically allocates memory.

What is the purpose of delete?

The delete operator releases dynamically allocated memory.

What is the difference between delete and delete[]?

delete is used for a dynamically allocated single object, while delete[] is used for a dynamically allocated array.

Manipulators

What is setw()?

setw() sets the minimum width of the next output field.

Which header file is required for setw() and setprecision()?

The <iomanip> header is required.

What does setprecision(2) do with fixed?

It displays two digits after the decimal point.

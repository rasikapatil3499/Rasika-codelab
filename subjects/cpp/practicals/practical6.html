What is an Inline Function?

Understand how inline functions work and where they can be useful in C++ programs.

Theory

An inline function is a function declared using the inline keyword. It is generally used for small functions that are called frequently.

When a function is declared inline, the compiler may replace the function call with the actual function code. This can reduce the overhead associated with a normal function call.

Inline functions are most suitable for short operations such as finding a square, maximum value, or performing a simple calculation.

inline returnType functionName(parameters) { // function body }
Function Call → Inline Function → Result
🌍

Real-Life Example

Imagine a billing system that repeatedly calculates a small service charge. Instead of repeatedly handling the overhead of a normal function call, a small calculation can be written as an inline function.

Similarly, small calculations such as tax, discount, percentage or maximum value can be implemented using inline functions.

Where & How Is It Used?

Small Calculations

Useful for short mathematical operations such as square, cube or percentage.

Frequently Called Functions

Suitable for functions that are called repeatedly during program execution.

Utility Functions

Small utility operations can be written as inline functions to keep the code concise.

Basic Syntax 

inline returnType functionName(parameters)
{
    // function body
}
PROBLEM 01

Square of a Number

Problem Statement

Write a C++ program to calculate the square of a number using an inline function.

Algorithm

  1. Start.
  2. Define an inline function named square().
  3. Accept a number from the user.
  4. Pass the number to the inline function.
  5. Calculate the square.
  6. Display the result.
  7. Stop.

C++ Program 

#include <iostream>
using namespace std;

inline int square(int n)
{
    return n * n;
}

int main()
{
    int num;

    cout << "Enter a number: ";
    cin >> num;

    cout << "Square = "
         << square(num);

    return 0;
}

Expected Output 

Enter a number: 5
Square = 25

Program Explanation

  • square() is declared using the inline keyword.
  • The function accepts an integer parameter.
  • It returns n * n.
  • The function is called using square(num).

Real-Life Connection

Square calculations are commonly required in geometry, engineering calculations and mathematical applications. A small frequently used calculation can be represented using an inline function.

Key Points

  • Use the inline keyword to declare an inline function.
  • Inline functions are generally suitable for small operations.
  • The compiler decides whether to actually inline the function.

PROBLEM 02

Maximum of Two Numbers

Problem Statement

Write a C++ program to find the maximum of two numbers using an inline function.

Algorithm

  1. Start.
  2. Define an inline function named maximum().
  3. Accept two numbers.
  4. Pass both numbers to the inline function.
  5. Compare the two numbers.
  6. Return the greater number.
  7. Display the maximum value.
  8. Stop.

C++ Program 

#include <iostream>
using namespace std;

inline int maximum(int a, int b)
{
    return (a > b) ? a : b;
}

int main()
{
    int a, b;

    cout << "Enter two numbers: ";
    cin >> a >> b;

    cout << "Maximum = "
         << maximum(a, b);

    return 0;
}

Expected Output 

Enter two numbers: 25 40
Maximum = 40
INLINE FUNCTION VISUALIZATION

Compare → Select → Return

The inline function compares both values and returns the greater number.

INPUT A 25 a
+
INPUT B 40 b
→
INLINE FUNCTION 40 maximum(a,b)

Program Explanation

  • maximum() is an inline function.
  • It accepts two integer parameters.
  • The conditional operator compares both values.
  • The greater value is returned to main().

Real-Life Connection

Finding the larger of two values is useful in result processing, salary comparison, product pricing and many decision-making applications.

Key Points

  • An inline function can accept multiple parameters.
  • It can contain a short expression or calculation.
  • The returned value can be directly used in cout.

Common Errors

Wrong Parameters

The number and type of arguments should match the function parameters.

Incorrect Comparison

Make sure the comparison returns the greater value correctly.

PROBLEM 03

Simple Interest

Problem Statement

Write a C++ program to calculate simple interest using an inline function.

Formula

Simple Interest (P × R × T) / 100
P Principal Amount
R & T Rate & Time

Algorithm

  1. Start.
  2. Define an inline function named simpleInterest().
  3. Accept principal amount, rate and time.
  4. Pass the values to the inline function.
  5. Calculate simple interest using the formula.
  6. Return the calculated interest.
  7. Display the simple interest.
  8. Stop.

C++ Program 

#include <iostream>
using namespace std;

inline float simpleInterest(
    float p, float r, float t)
{
    return (p * r * t) / 100;
}

int main()
{
    float p, r, t;

    cout << "Enter principal amount: ";
    cin >> p;

    cout << "Enter rate of interest: ";
    cin >> r;

    cout << "Enter time: ";
    cin >> t;

    cout << "Simple Interest = "
         << simpleInterest(p, r, t);

    return 0;
}

Expected Output 

Enter principal amount: 10000
Enter rate of interest: 5
Enter time: 2
Simple Interest = 1000
INLINE FUNCTION VISUALIZATION

Financial Calculation

The values are passed to the inline function and the simple interest is calculated.

PRINCIPAL ₹10,000 P
+
RATE 5% R
+
TIME 2 T
→
RESULT ₹1,000 Simple Interest

Program Explanation

  • simpleInterest() is declared as an inline function.
  • It accepts principal, rate and time as parameters.
  • The formula (P × R × T) / 100 is applied.
  • The calculated value is returned to main().

Real-Life Connection

Simple interest calculations can be used in basic banking, loan calculations, savings calculations and financial education applications.

Key Points

  • Inline functions can work with different data types.
  • Multiple parameters can be passed to an inline function.
  • Inline functions are useful for short calculations.

Common Errors

Formula Error

Use the correct simple interest formula: (P × R × T) / 100.

Data Type Error

Use a suitable data type such as float for decimal values.

Yes. An inline function can accept one or more parameters like a normal function.

Can an inline function return a value?

Yes. It can return a value using its specified return type.

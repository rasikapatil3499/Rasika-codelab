FOUNDATION 06

What is an Expression?

Expressions are where values, variables and operators come together to produce a result.

01 — BASIC IDEA

An expression produces a value.

An expression is a combination of constants, variables, operators and function calls that can be evaluated to produce a value.

Σ
SIMPLE DEFINITION

An expression is a combination of operands and operators that is evaluated to produce a result.

02 — SIMPLE EXAMPLE

Start with something simple.

OPERAND 10
+
OPERAND 20
=
RESULT 30
10 + 20

The complete 10 + 20 is an expression, and its evaluated result is 30.

04 — EXPRESSION EVALUATION

How does C++ evaluate an expression?

When an expression contains multiple operators, C++ follows rules such as precedence and associativity to determine the evaluation order.

Given
a + b * 2
STEP 01 Evaluate b * 2 Multiplication has higher precedence than addition.
↓
STEP 02 Add a to the result The addition operation is performed next.
↓
FINAL RESULT a + (b × 2)
05 — STEP-BY-STEP VISUALIZATION

Let's evaluate 5 + 3 * 2.

START 5 + 3 × 2 Original expression
→
STEP 1 5 + 6 3 × 2 = 6
→
STEP 2 11 5 + 6 = 11
Why is the answer 11?

Multiplication has higher precedence than addition, so 3 * 2 is evaluated first.

06 — PARENTHESES

Parentheses can change the order.

Parentheses explicitly group part of an expression and can change which operation is evaluated first.

WITHOUT PARENTHESES 5 + 3 * 2 11 Multiplication first
VS
WITH PARENTHESES (5 + 3) * 2 16 Addition first
07 — TYPES OF EXPRESSIONS

Expressions can perform different kinds of operations.

+

Arithmetic

a + b

Produces a numerical result.

>

Relational

a > b

Produces a boolean result.

&&

Logical

a && b

Combines logical conditions.

=

Assignment

x = 10

Assigns a value to a variable.

08 — EXPRESSION RESULT

The result depends on the data types.

The types of the operands influence the type and behavior of an expression.

INTEGER DIVISION 5 / 2 2 Both operands are integers.
FLOATING-POINT DIVISION 5.0 / 2.0 2.5 Operands are floating-point values.

10 — COMMON ERRORS

Expression mistakes to avoid.

01

Ignoring precedence

2 + 3 * 4

Understand which operation is performed first.

02

Unexpected integer division

7 / 2 → 3

Integer operands produce integer division.

03

Confusing assignment and comparison

x = 5

Assignment and equality comparison are different operations.

04

Overcomplicated expressions

a + b * c - d / e

Use parentheses when grouping would improve clarity.

FOUNDATION 05

What is an Operator?

Operators are symbols that tell a program to perform an operation on one or more values.

01 — BASIC IDEA

An operator performs an operation.

In C++, operators are special symbols used to perform calculations, comparisons, assignments and logical operations.

+
SIMPLE DEFINITION

An operator is a symbol that tells the computer to perform a specific operation on one or more operands.

02 — OPERATOR + OPERAND

First understand the operands.

The values or variables on which an operator works are called operands.

OPERAND 10
+
OPERAND 20

RESULT 30
10 + 20

10 and 20 are operands, while + is the operator.

= means assignment.

The assignment operator stores a value in a variable.

→

Important
  • = is the assignment operator.
  • It does not mean "is equal to" in the mathematical sense.
  • Comparison for equality uses ==.

09 — INCREMENT & DECREMENT

Change a value by one.

START count = 5
++
AFTER INCREMENT count = 6
INCREMENT.CPP EXAMPLE

10 — C++ PROGRAM

Putting operators together.

OPERATORS.CPP EXAMPLE 
#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int b = 5;

    int sum = a + b;
    int difference = a - b;
    int product = a * b;

    cout << sum << endl;
    cout << difference << endl;
    cout << product;

    return 0;
}
INPUT VALUES a = 10, b = 5
→
OPERATIONS +, -, *
→
RESULTS 15, 5, 50
11 — IMPORTANT

Operators don't always execute left-to-right.

When an expression contains multiple operators, C++ uses rules such as operator precedence and associativity to determine the order in which operations are performed.

2 + 3 * 4
STEP 1 3 × 4 = 12
→
STEP 2 2 + 12 = 14
Result

2 + 3 * 4 produces 14, not 20, because multiplication has higher precedence than addition.

12 — REMEMBER

Key Takeaways

✓ Operators perform operations on operands.
✓ Arithmetic operators perform mathematical calculations.
✓ Assignment operators store values in variables.
✓ Relational operators compare values.
✓ Logical operators work with conditions.
✓ Operator precedence affects expression evaluation.

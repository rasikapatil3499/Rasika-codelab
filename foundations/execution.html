FOUNDATION 02

How Does a Program Execute?

You write C++ code in a human-readable form. But how does that code become instructions that the computer can execute?

01 — BASIC IDEA

The computer does not directly execute C++ source code.

A C++ program is written using a language that humans can understand. The computer's processor ultimately works with machine instructions.

⚙
CORE IDEA

Source Code → Translation → Executable → Execution

03 — SOURCE CODE

Step 1: Write the program

The programmer first creates a source file containing C++ instructions.

PROGRAM.CPP SOURCE CODE 
#include <iostream>
using namespace std;

int main()
{
    int a = 10;
    int b = 20;

    cout << a + b;

    return 0;
}
04 — PREPROCESSING

Step 2: Preprocessor prepares the source

Before compilation, preprocessing directives are handled. For example, an #include directive tells the preprocessor to include the required header information.

#

#include <iostream>

This provides declarations needed for standard input/output operations such as cout.

05 — COMPILATION

Step 3: Compiler translates the program

The compiler analyzes the C++ source code and translates it into lower-level code suitable for the target system.

Step 5: Load the program into memory

When you start an executable program, the operating system creates a process and loads the necessary program information into memory.

10 — WHAT IF SOMETHING IS WRONG?

The program may stop before execution.

Different problems are detected at different stages. Understanding the stages makes errors easier to understand.

01

Syntax / Compilation Error

The compiler cannot translate the source because the code violates language rules.

02

Linker Error

Required symbols or libraries cannot be resolved during linking.

03

Runtime Error

A problem occurs while the program is executing.

04

Logical Error

The program runs but produces an incorrect result because the logic is wrong.

FOUNDATION 03

What is a Variable?

A variable is more than just a name in your C++ program. It represents data that the program needs to store and work with.

01 — BASIC IDEA

A variable is a named storage location.

A variable allows a program to give a name to a piece of stored data. The program can then use that name to access or modify the data.

x
SIMPLE DEFINITION

A variable is a named location used by a program to store a value in memory.

02 — REAL WORLD ANALOGY

Think of a labeled box.

Imagine several boxes. Each box has a label and contains something inside it.

04 — VISUALIZE MEMORY

Where does the variable actually exist?

When a variable is used during program execution, storage is associated with that variable in the program's memory. The exact address is determined by the running environment.

VARIABLE age
TYPE int
VALUE 20
MEMORY
0x1004
20 value stored for age

Important: The address shown above is only a conceptual example. You should not assume that a variable will actually be stored at that address.

09 — COMMON MISTAKES

Things beginners often confuse

01

Using a variable before declaring it

age = 20;

The variable should be declared before it is used.

02

Using an incompatible value

int age = "twenty";

The value should be appropriate for the variable's type.

03

Confusing = with ==

age = 20;

= performs assignment, while == is used for comparison.

04

Choosing unclear names

x = 85;

Meaningful names such as marks make programs easier to understand.

10 — REMEMBER

Key Takeaways

✓ A variable is a named location used to work with stored data.
✓ A variable has a name, type and value.
✓ Variables can be assigned new values.
✓ Data types describe the kind of data a variable represents.
✓ A variable name identifies the variable; its value is the data.
✓ Variables are closely connected with memory.

FOUNDATION 01

What is a Program?

Before learning C++ syntax, understand the most basic idea: What exactly is a program?

01 — BASIC IDEA

A program is a set of instructions.

A program is a sequence of instructions written to tell a computer how to perform a particular task or solve a particular problem.

</>
SIMPLE DEFINITION

A program is a collection of instructions that a computer follows to produce a desired result.

02 — REAL WORLD CONNECTION

Think about a recipe.

A recipe tells you exactly what to do, step by step. A computer program works in a similar way.

Program = Instructions + Data + Logic

05 — C++ CONNECTION

So where does C++ come in?

C++ is a programming language used to write instructions that can be translated and executed by a computer.

C++ PROGRAM Example 01 
#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World";

    return 0;
}
What did we just write?
  • #include <iostream> gives access to standard input/output functionality.
  • main() is the starting point of this C++ program.
  • cout sends text to the output.
  • return 0 indicates successful completion of the program.
06 — WHAT HAPPENS?

From code to result

The code we write is not directly understood by the CPU. It goes through several stages before the computer executes it.

01 C++ Source Code Program written by the programmer
02 Translation Compiler translates the source code
03 Execution Computer executes the instructions
04 Output The program produces a result
07 — KEY TERMS

Words you should know

Program

Set of instructions for solving a problem.

Source Code

Human-readable code written by a programmer.

Programming Language

A language used to communicate instructions to a computer.

Programmer

A person who designs and writes computer programs.

Input

Data supplied to a program.

Output

The result produced by a program.

08 — REMEMBER

Key Takeaways

✓ A program is a set of instructions.
✓ Programs are written to solve problems.
✓ Programs work with data.
✓ Logic determines how a program behaves.
✓ C++ is a programming language used to create programs.
✓ A program generally transforms input into output.

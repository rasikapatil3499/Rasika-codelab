FOUNDATION 07

What is Input & Output?

Learn how a C++ program receives data from the user, processes it, and displays the result.

01

What is Input & Output?

Input and output are the basic ways a program communicates with the outside world.

Simple Definition

Input means providing data to a program, while Output means displaying the result produced by the program.

INPUT User Provides Data
→
PROCESS C++ Program Processes Data
→
OUTPUT Screen Shows Result
02

Think of it in the Real World

Input and output are not unique to computers.

Example: Calculator

Suppose you want to calculate the sum of two numbers.

10 Input
+
20 Input
→
30 Output

The numbers 10 and 20 are input. The program performs addition and produces 30 as output.

03

Taking Input using cin

C++ uses cin to receive input from the standard input device, normally the keyboard. 

#include <iostream>
using namespace std;

int main()
{
    int age;

    cin >> age;

    return 0;
}

How does it work?

  1. int age; creates an integer variable.
  2. cin waits for the user to enter data.
  3. >> sends the entered value into the variable.
  4. The value is stored in age.
04

Displaying Output using cout

C++ uses cout to display information on the screen. 

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello C++";

    return 0;
}
OUTPUT 
Hello C++

Remember

The operator << is used with cout to send data toward the output stream.

05

Input + Processing + Output

Most beginner C++ programs follow this basic pattern. 

#include <iostream>
using namespace std;

int main()
{
    int a, b, sum;

    cout << "Enter two numbers: ";

    cin >> a >> b;

    sum = a + b;

    cout << "Sum = " << sum;

    return 0;
}
INPUT a = 10 b = 20
→
PROCESS sum = a + b
→
OUTPUT Sum = 30
OUTPUT 
Enter two numbers: 10 20
Sum = 30
06

What happens in Memory?

Input is not simply displayed. It is stored in variables in memory.

KEYBOARD 25
→
VARIABLE age 25
→
SCREEN 25

Conceptual Flow

When the user enters 25, the input is received by the program and stored in the variable age. When cout is used, that value is sent to the output stream and displayed on the screen.

07

>> and <<

These operators are commonly used with C++ input and output streams.

>>

Extraction Operator

Used with cin to extract data from the input stream.

cin >> age;
<<

Insertion Operator

Used with cout to insert data into the output stream.

cout << age;
08

Taking Multiple Inputs

Multiple values can be read using a single cin statement. 

int a, b, c;

cin >> a >> b >> c;

If the user enters:

10 20 30

then:

  • a = 10
  • b = 20
  • c = 30
09

Text Input and Output

Input and output are also used with strings. 

#include <iostream>
#include <string>
using namespace std;

int main()
{
    string name;

    cout << "Enter your name: ";
    cin >> name;

    cout << "Hello " << name;

    return 0;
}
EXAMPLE OUTPUT 
Enter your name: Rasika
Hello Rasika
10

Common Errors

Avoid these common beginner mistakes.

❌ Wrong

cout >> age;

cout normally uses <<.

❌ Wrong

cin << age;

cin normally uses >>.

❌ Wrong

cin >> 25;

Input must normally be stored in a variable or another suitable input destination.

LLO CONNECTION

Why is Input & Output important?

Your first C++ practical requires you to evaluate expressions using input/output functions. Therefore, understanding cin, cout, variables and operators is essential.

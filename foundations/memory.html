FOUNDATION 04

What is Memory?

Every running program needs a place to store instructions, values, objects and temporary data. That place is memory.

01 — BASIC IDEA

Memory is where a running program keeps information.

Computer memory provides storage that programs can use while they execute. When a C++ program runs, different kinds of information require storage.

▦
SIMPLE DEFINITION

Memory is a storage area used by a computer to hold data and instructions needed during execution.

02 — REAL WORLD ANALOGY

Think of memory like a collection of numbered lockers.

Each memory location can be thought of as having an address. Data can be stored at those locations.

ADDRESS 1000 Data 25
ADDRESS 1001 Data 42
ADDRESS 1002 Data 75
ADDRESS 1003 Data 10

The addresses above are simplified examples for learning. Actual memory addresses are much larger values.

03 — BITS & BYTES

Every memory location has an address.

An address identifies a location in memory. In C++, pointers allow programs to work explicitly with memory addresses.

Remember this distinction
  • Address tells us where data is stored.
  • Value tells us what data is stored.
  • A variable provides a convenient name for working with stored data.

06 — PROGRAM MEMORY

A running program uses different memory areas.

A simplified process-memory model commonly used for learning divides memory into several conceptual regions.

01

Code / Text

Contains program instructions.

02

Data

Stores certain global and static program data.

03

Heap

Used for dynamic memory allocation.

04

Stack

Used for function calls and automatic local data.

Important: This is a simplified educational model. Actual process memory layout depends on the operating system, compiler, architecture and runtime environment.

07 — STACK & HEAP

Two memory areas you will use repeatedly in C++.

S

Stack

  • Used for function calls.
  • Automatic local variables commonly reside here.
  • Managed automatically.
  • Very important when learning recursion.
H

Heap

  • Used for dynamic memory allocation.
  • Memory can be requested during execution.
  • Important for pointers and dynamic objects.
  • Requires appropriate memory management.

09 — WHY IT MATTERS

Why should a C++ programmer understand memory?

01

Variables

Variables need storage while a program executes.

02

Arrays

Array elements are stored in an organized memory region.

03

Pointers

Pointers can store and work with memory addresses.

04

Functions

Function calls involve stack memory and execution state.

05

Objects

Objects require memory to hold their state.

06

Dynamic Memory

Dynamic allocation directly involves memory management.

10 — REMEMBER

Key Takeaways

✓ Memory stores information required by a running program.
✓ Memory locations can be identified by addresses.
✓ A value is different from the address where it is stored.
✓ A variable provides a convenient name for stored data.
✓ Stack and heap are important conceptual areas of process memory.
✓ Understanding memory is essential for learning pointers.
